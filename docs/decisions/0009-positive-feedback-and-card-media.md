# 0009. 추천은 개수만(싫어요 없음) · 카드 호버 미디어 · 미디어 5개 이상

- 상태: 확정 (2026-11-27, 사용자 피드백 — PG01 · PG03 1차 검토)
- 바꾸는 것: [0008](0008-mvp-product-defaults.md) D2(카드 호버 = 스크린샷 3장 순환)

## 결정

| # | 항목 | 결정 |
| --- | --- | --- |
| 1 | 평가 방식 | **추천은 개수만 센다.** 싫어요 · 비추천 · 별점 · 추천률(%) 없음. 플레이한 사람이 `추천하기`를 누르고, 다시 누르면 취소 |
| 2 | 리뷰 | 글 + 태그. 리뷰에 찬반 판정을 붙이지 않는다(쓴 사람이 추천했으면 `추천함` 표시만). 아쉬운 점은 리뷰 글로 |
| 3 | 신고 | 싫어요 대신 **게임 신고**는 둔다(게임 상세 · 플레이 화면 · 리뷰마다, 화면 `SH04`) |
| 4 | 카드 숫자 | 숫자는 혼자 쓰지 않는다 — 항상 아이콘 + 글자: `👍 추천 214 · 💬 리뷰 38`. 표본이 적어도 그대로 보여 준다(퍼센트가 없으니 10개 미만 숨김 규칙도 없앰) |
| 5 | 카드 오른쪽 아래 버튼 | 호버 시 바로 실행되는 게임은 **플레이**, 설치형만 있는 게임은 **다운로드** 아이콘 |
| 6 | 호버 미리보기 | 메이커가 영상을 올렸으면 **영상 1개를 소리 없이 반복**, 아니면 **이미지를 2.5초마다 순환**. 모든 카드에 같은 규칙(홈 · 전체 게임 · 검색 · 메이커 페이지 …) |
| 7 | 업로드 필수 미디어 | **이미지 · 영상 합쳐 5개 이상**(심사 보완 요청 사유). 영상은 선택 |

## 이유

- 플랫폼의 분위기를 긍정적으로 — 인디 첫 작품이 싫어요 숫자로 상처받지 않게. 문제는 신고와 리뷰 글로 다룬다.
- `28`, `13` 같은 숫자만 있으면 무엇인지 모른다(사용자 지적). 글자를 붙이는 비용은 거의 없다.
- 호버 미리보기는 "해 보고 싶은지" 판단을 가장 빨리 돕는다. 5개 이상이면 순환이 한 바퀴 12.5초 정도로 충분히 길다.

## 성능 · 비용 규칙 (구현 때)

- 카드 그림: 업로드 때 서버 대신 **브라우저에서** 줄여 저장(무료 플랜 CPU 10ms 제약) — 카드용 480px · WebP/AVIF · 40KB 안쪽, 상세용 1280px.
- 호버 미디어는 **호버 300ms 뒤에야** 불러온다(스쳐 지나가는 마우스는 안 받음). 영상은 `preload="none"` · `muted` · `playsinline`, 480p · 15초 · 2MB 안쪽(업로드 때 검사).
- 저장: R2 무료 10GB 안 — 게임당 미리보기 영상 2MB + 이미지 5장 × 2크기 ≈ 3MB → 1,000개 게임에 3GB.
- `prefers-reduced-motion` 이면 순환 · 영상 자동 재생을 끈다(설정에서도 끔).

## 영향

- 화면: 카드가 있는 모든 페이지, `PG05` 추천 줄 · 리뷰, `PG07` 추천 버튼, `PG10` 리뷰 정렬(추천만/비추천만 → 추천한 사람), `MG07` 피드백함, `MG02` · `MG04` · `AD01` 미디어 개수 규칙.
- 데이터: `recommendations(game_id, user_id)` 한 테이블 + 게임별 개수 캐시. 리뷰 테이블에 찬반 열 없음.
