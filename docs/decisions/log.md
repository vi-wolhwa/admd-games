| 날짜 | 결정 | 이유 |
| --- | --- | --- |
| 2026-11-26 | 스타일링은 Tailwind CSS 4 로 시작 | sv 공식 애드온, 디자인 토큰을 CSS 변수로 정의하기 쉬움. 디자인 시스템 설계 후 재검토 |
