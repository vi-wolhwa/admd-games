# 0008. MVP 제품 기본값: 라이트만 · 스크린샷 미리보기 · 활동 기본 공개

- 상태: 승인 (2026-11-26, 사용자 결정)
- 등급: A (핵심 UX · 비용)

## 결정

| # | 질문 | 결정 | 메모 |
| --- | --- | --- | --- |
| D1 | 다크 모드 | **MVP 는 라이트만** | 다크 토큰은 `tokens.css` 에 그대로 둔다(`data-theme`·`prefers-color-scheme` 연결만 끈 상태). 출시 후 켤 때 화면별 점검만 하면 됨. 플레이 화면(`PG-PLAY`)의 먹색 바는 테마와 무관한 고정 다크라 그대로 |
| D2 | 카드 호버 미리보기 | **스크린샷 3장 순환** | 필수 업로드 자산이라 추가 비용 0. 영상은 저장 비용 검토 후 |
| D3 | "친구가 플레이 중인 게임" 등 내 활동 공개 | **기본 공개** | 아래 조건을 반드시 지킨다 |

## D3 을 지키기 위한 조건 (개인정보 · 신뢰)

1. **처음 로그인(얼굴 만들기) 화면에서 알린다**: "친구에게 지금 하는 게임이 보여요 · 설정에서 끌 수 있어요" + 그 자리에서 바로 끄는 스위치.
2. 설정 → 공개 범위에서 언제든 끔. 끄면 기존 활동 표시도 즉시 사라짐.
3. 공개 범위는 **친구에게만**(서로 수락한 사이). 모르는 사람·검색 엔진에는 보이지 않는다.
4. 개인정보처리방침에 수집 항목(플레이 기록)·공개 범위를 적는다.
