# 0011. 플랫폼이 아는 것만 약속한다 · 즐겨찾기(별) · 누를 수 있는 것은 테두리

- 상태: 확정 (2026-11-27, 사용자 피드백 PG05 3차)
- 바꾸는 것: ADR 0009 #8(추천 · 리뷰 권한), 디자인 F3(테두리 없는 회색 채움 보조 버튼)

## 1. 게임 상태 — 플랫폼이 실제로 아는 것만

| 상태 | 플랫폼이 아는 근거 | 주 버튼 | 함께 보이는 것 |
| --- | --- | --- | --- |
| 처음 | 플레이 기록 없음 | 지금 플레이 | |
| 해 본 적 있음 | 플레이 화면이 연 · 닫은 시각을 기록(브라우저 게임) | **플레이** | "어제 마지막으로 함 · 모두 1시간 12분" |
| 진행 중 (SDK) | 게임이 SDK 로 진행도를 알려 줌 | **이어하기** | 진행 막대 |
| 다운로드 | 설치형 빌드 | 다운로드 | 보안 검사 |
| 이 기기 불가 | 메이커가 고른 기기 | 휴대폰으로 링크 보내기 | |

- **'이어하기'는 진행도를 아는 게임에서만.** 대부분의 게임은 저장 여부를 플랫폼이 알 수 없다. 게임 자신의 저장(브라우저 저장소)은 게임마다 다른 출처(origin)에서 돌기 때문에 같은 브라우저에서 다시 열면 게임이 알아서 이어 간다 — 버튼 이름은 그냥 '플레이'.
- **'다시 하기' · '완료' 없음.** 엔딩 · 클리어는 게임 안의 일이라 플랫폼이 모른다(SDK 로 알려 주면 그때 '끝까지 함' 표시만).
- 홈의 '이어하기' 줄은 **'최근 플레이'** 로. 진행도를 아는 게임만 '이어하기' 버튼.
- **'친구에게 도전장' → '친구에게 보내기'**(링크 공유). 기록 비교는 점수를 알아야 하므로 SDK 순위표가 생긴 뒤(L2).

## 2. 추천 · 리뷰 = 로그인만 (ADR 0009 #8 수정)

- 해 봐야 할 수 있게 막지 않는다. 추천 · 리뷰는 많을수록 좋다(사용자).
- 대신 리뷰에 **플레이 시간을 그대로 보여 준다** — 기록이 없으면 "플레이 기록 없음". 읽는 사람이 판단한다(Steam 방식).
- 조작 방지는 다른 수단으로: 계정당 게임당 추천 1번, 메이커 본인 불가, 새 계정의 짧은 시간 대량 추천은 운영 대기열로.

## 3. 즐겨찾기 — 별

- '저장'(책갈피) → **즐겨찾기**(☆/★). 라이브러리 탭 이름도 '즐겨찾기'.
- 하트가 아닌 이유: 하트는 '좋아요'로 읽혀 공개 신호인 **추천(엄지)** 과 헷갈린다. 즐겨찾기는 나만 보는 목록이라 브라우저 즐겨찾기와 같은 별이 맞다.

## 4. 누를 수 있는 것은 테두리, 정보 묶음은 회색 바탕

- 보조 버튼 · 칩(필터 · 태그 고르기) · 정렬 · 드롭다운 · 화살표 = 흰 바탕 + 1px 테두리(`--line-strong`: 라이트 #D3D6DA · 다크 #3B4046). 고른 칩 · 정렬 = 먹색으로 채움.
- 정보 묶음(핵심 4칸 · 플레이 정보 · 리뷰 요약 · 진행 상자)과 붙은 꼬리표(카드 장르 · 고른 말) = 회색 바탕, 테두리 없음.
- 이유: 회색 채움 하나로 버튼 · 칩 · 정보 상자를 모두 그리면 무엇을 누를 수 있는지 구분되지 않았다(사용자 지적). 모양으로 역할을 나눈다.

## 5. 문제 알리기 (게임 신고 이름 변경)

- 버튼 이름 **'문제 알리기'**, 고르는 사유: 실행이 안 돼요 · 버그 · 설명과 달라요 · 부적절한 내용 · 저작권.
- 실행 · 버그 · 설명 → **메이커 피드백함(MG07)** 으로 가고 운영자도 본다. 부적절 · 저작권 → 운영자 신고 처리(AD02).
- 이유: '신고'만 있으면 처벌로만 읽힌다. 대부분은 메이커가 고치면 되는 문제다.
- 리뷰 · 댓글의 '신고'는 그대로(그쪽은 실제로 부적절한 글을 알리는 기능).
