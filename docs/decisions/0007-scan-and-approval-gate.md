# 0007. 보안 검사와 공개 승인: 셀프 호스트 러너 + 운영자 승인 필수

- 상태: 승인 (2026-11-26, 사용자 승인)
- 등급: A
- 근거 조사: [`docs/product/research-scan-storage.md`](../product/research-scan-storage.md)

## 배경

Workers 무료 플랜에서는 백신을 돌릴 수 없다. 무료 · 약관 준수 선택지는 셀프 호스트 GitHub Actions 러너(ClamAV · Windows Defender)뿐이다. VirusTotal 공개 API 는 비상업 전용이고 올린 파일이 외부와 공유되어 쓰지 않는다.

사용자 요구: **"내가 승인하지 않은 게임이 자동으로, 보안 검사도 거치지 않고 플랫폼에 공개되지 않아야 한다. 결국 내가 승인해야 한다."**

## 결정

1. 검사: **셀프 호스트 러너**(사용자 PC 또는 VM, 실행 금지 전용 계정)에서 ClamAV(+ Defender). VirusTotal 사용 안 함.
2. **공개에는 두 관문이 모두 필요하다**
   - 관문 1 — 자동 검사 `clean` (설치형 파일 전부. 웹 빌드 zip 도 같은 검사를 거친다)
   - 관문 2 — **운영자(사용자)의 명시적 공개 승인** (`AD-REVIEW` 심사 대기열)
3. 어떤 경우에도 자동 공개 없음: 검사 통과만으로, 시간 경과만으로, 메이커 재제출만으로 공개되지 않는다. 새 버전(업데이트)도 같은 두 관문을 거친다 — 그동안은 이전 승인 버전이 계속 서비스된다.
4. 검사가 `clean` 이 아니면(검사 중 · 주의 · 차단 · 러너 응답 없음) **승인 버튼이 잠긴다.**

## 상태 기계

```
작성 중 → (제출) → 검사 중 ─clean→ 심사 대기 ─승인→ 공개
                    │                  ├─보완 요청→ 작성 중
                    ├─주의/차단→ 보완 요청 · 반려   └─반려→ 반려
                    └─러너 응답 없음(24h)→ 검사 중 유지 + 운영자 알림
```

- 상태 전이는 서버(도메인)에서만, 전이 기록(누가 · 언제 · 왜)은 운영 로그에 남긴다.
- `public` 영역으로의 파일 이동(ADR 0006 `promote`)은 **승인 전이 안에서만** 호출된다.
- 러너 콜백은 HMAC 서명 검증. 비밀값은 `.env.example` 에 이름만, 실제 값은 사용자가 넣는다.

## 결과

- 사용자 PC 가 꺼져 있으면 검사가 밀린다 → 메이커 화면에 "보통 하루" 안내, 24시간 넘으면 대기열에 표시(시안 `심사 대기열`).
- 화면 문구는 "문제를 찾지 못했어요" — 안전 보장 단언 금지.
- 설치 파일 한 개당 최대 500MB (ADR 0006).
