# 킥오프 인터뷰 기록

- 일시: 2026-11-26
- 목적: 디자인 콘셉트와 요구사항의 근거가 되는 결정 중 사용자만 답할 수 있는 것을 확정한다. 나머지 요구사항은 사용 시나리오 시뮬레이션으로 도출한다(`docs/product/scenarios.md`, 작성 예정).

## 확정된 답

| 질문 | 답 | 설계에 주는 영향 |
| --- | --- | --- |
| 기존 플랫폼과의 차별점 | ① **만든 사람이 보이는 곳** ② **고르는 재미(큐레이션)** ③ **같이 노는 곳** + 다운로드 파일의 **보안 검사 결과를 보여 주어 신뢰**를 준다 | 메이커가 화면의 주인공(게임 옆에 항상 사람이 있음). 편집된 큐레이션이 홈의 뼈대. 친구·랭킹·멀티·커뮤니티 동선. 다운로드 게임에 검사 배지·리포트 |
| 출시 시점 게임 공급 | **처음부터 누구나 업로드** | 출시 범위에 MakersGround 업로드·게임 관리·심사(검수) 상태·신고·운영자 도구가 포함된다 |
| 실행 방식 | **브라우저 + 다운로드** | 상세 페이지 CTA 분기(플레이/다운로드), 플랫폼·용량·버전·요구사양, 다운로드 파일 보안 검사 |
| 기기·언어 | **PC 우선 + 모바일 대응, 한국어.** 영어는 필요 시 추후. **MakersGround 는 모바일 사용이 많을 수 있음** | PlayGround 는 데스크톱 기준 설계 + 모바일 탐색·라이브러리·터치 게임. MakersGround 는 모바일 화면을 1급으로 설계. 문구는 i18n 키로 뺄 수 있게 |

"누르면 바로 플레이"는 차별점으로 고르지 않았지만, 브라우저 게임에서는 기본 품질(table stakes)로 유지한다.

## 이전 결정과 달라진 점

- 2026-11-26 앞선 대화의 "MVP = PlayGround 먼저"는 **구현 순서**로 유지하되, 누구나 업로드가 출시 조건이므로 MakersGround 의 업로드·게임 관리 흐름은 첫 출시 범위에 들어간다. (정확한 출시 범위는 시나리오 시뮬레이션 후 PRD 에서 확정)

## 기술 확인이 필요한 것 (디자인과 병행 조사)

- 무료 바이러스 검사 방법: VirusTotal 공개 API 는 비상업 용도 제한이 있음 → ClamAV 를 GitHub Actions 에서 돌리는 방식 등 대안 검토. 결과 화면은 방식과 무관하게 설계한다.
- 다운로드 파일 저장소: Cloudflare R2 무료 10GB(결제 수단 등록 요구 여부 확인), GitHub Releases 등 대안.
- 누구나 업로드에 따른 운영: 심사 대기열, 신고 처리, 저작권·악성코드 대응 정책.
