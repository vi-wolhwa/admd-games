# 게임 정보 필드 정의 (2026-11-27)

게임 상세(PG05) · 카드 · 필터에 보이는 정보는 **모두 여기서 온다.** 새 정보를 화면에 넣기 전에 이 표에 먼저 넣고 네 가지를 따진다:
① 누가 입력하나(메이커 / 플랫폼 자동) ② 얼마나 자주 바뀌고 누가 고치나 ③ 모든 게임에 해당하나 ④ 플레이어의 어떤 결정을 돕나.

## 메이커가 업로드 때 입력 (MG04 업로드 마법사)

| 필드 | 입력 방식 | 필수 | 보이는 곳 | 메모 |
| --- | --- | --- | --- | --- |
| 제목 | 글 40자 | ● | 어디나 | |
| 한 줄 소개 | 글 60자 | ● | 상세 패널 · 검색 | 카드에는 안 보임(카드는 그림이 말함) |
| 소개 · 특징 | 글(서식 최소) | ● | 소개 탭 | 메이커가 쓰는 글이라 메이커가 관리. 플랫폼이 숫자를 요구하지 않음 |
| 태그 | 1~5개, 자동완성 | ● | 카드 · 패널 · 필터 | ADR 0010 |
| 대표 그림 | 1920×1080 1장 | ● | 카드 · 미리보기 첫 칸 | |
| 미리보기 미디어 | 이미지 · 영상 합쳐 5개 이상 | ● | 미리보기 · 카드 호버 | ADR 0009. 영상은 15초 안쪽 · 2MB 미리보기 |
| 기기 | 고르기: PC · 휴대폰 · 패드 (여럿) | ● | 패널 '기기' · 필터 | 브라우저 게임만 휴대폰 · 패드 선택 가능 |
| 조작 | 고르기: 키보드 · 마우스 · 터치 · 게임패드 (여럿) | ● | (화면에는 안 보임 — 2026-11-28) | 데이터만 둠 |
| 한 판에 | 고르기: 10분 안쪽 · 10~30분 · 30분 이상 | ● | 패널 · 카드 · 필터 | **겹치지 않는 구간 3개**(2026-11-28, 5구간 누적에서 줄임) — 분 단위 정확한 값은 업데이트마다 틀어짐 |
| 매일 이어서 | 체크 | | 패널 · 카드 · 필터('한 판에' 맨 아래) | 진행이 저장돼 날마다 들러 이어 하는 게임(예: 옛 웹게임 패션시티 · 쁘띠카페). 한 판 시간과 별개라 따로 체크(2026-11-28). 저장을 누가 하나(메이커 서버 / 플랫폼 SDK)는 SDK 때 결정 |
| 인원 | 같은 기기에서 최소~최대(1 = 혼자 가능) | ● | 패널 · 카드 칩 · 필터 | 필터: 혼자서(최소 1) · 둘이서(최대 2 이상) · 온라인(아래) — 2026-11-28 |
| 온라인 | 체크 | ● | 패널 · 소개 탭 '인원'에 붙임 · 인원 필터 | 온라인 = **인터넷으로 다른 사람과 같이 플레이**. 순위만 있는 게임은 해당 없음(2026-11-28 좁힘 — 인원 필터에 들어가면서) |
| 언어 | 고르기(여럿) | ● | 소개 탭 '언어' | 게임 안 글자의 언어. 패널에는 안 둠(결정에 덜 중요) |
| 이용 주의 | 체크: 폭력 · 공포 · 깜빡임 · 큰 소리 · 없음 | ● | (화면에서 뺌 — 사용자 결정 2026-11-28) | 데이터만 둠 |
| 최소 사양 | 글 한 줄 | 설치형만 | 소개 탭 '사양' | |

**넣지 않는 것**: 스테이지 수 · 엔딩 수 · 콘텐츠 분량 같은 숫자(게임마다 구조가 다르고, 업데이트마다 메이커가 고쳐야 함), 엔진(플레이어 결정에 거의 영향 없음 — 원하면 소개 글에 쓰면 됨), 저장 방식(SDK 클라우드 저장이 생기면 플랫폼이 자동 표시).

## 플랫폼이 자동으로 아는 것

| 필드 | 출처 | 보이는 곳 |
| --- | --- | --- |
| 실행 방식(브라우저 / 다운로드 — 둘 다 '어디서 하나', 2026-11-28) | 올린 빌드 종류 | 카드 칩 · 패널 · 필터 |
| 보안 검사 결과 | 검사 러너(ADR 0007) | 설치형 패널 · 리포트 |
| 공개일 · 최근 업데이트(버전 · 날짜) | 심사 통과 기록 | 소개 탭 · 업데이트 탭 |
| 추천 수 · 리뷰 수 | 추천 · 리뷰 테이블 | 카드 · 패널 · 리뷰 탭 |
| 내 플레이 시간 · 마지막 플레이 | 플레이 화면 기록(브라우저 게임만) | 이어하기 · 라이브러리 · 리뷰 맥락 |
| 진행도 · 도전과제 | SDK 를 쓴 게임만 | 이어하기 · 패널(진행 중) |
| 메이커 정보 | 메이커 프로필 | 소개 탭 맨 위 메이커 카드 |

## 상세 패널(PG05 오른쪽)에 무엇을 두나

첫 화면에서 "할까 말까"를 정하는 데 필요한 것만: **제목 → 한 줄 소개 → 태그 → 핵심 4칸(실행 · 기기 · 한 판에 · 인원) → 상태별 버튼 → 추천.** 메이커 · 언어 · 조작 · 공개일 같은 나머지는 소개 탭 오른쪽에 한 번만.
