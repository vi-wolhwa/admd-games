# 이어하기 · 진행도 · 도전과제 — 가능한지 검토 (2026-11-27)

사용자 질문(PG01 피드백): "설치형 게임을 몇 퍼센트 했는지 알 방법이 없지 않나? 도전과제도 게임 안에 스크립트를 넣어야 하는데 가능한가? 도전과제 없는 게임이 훨씬 많을 것이다. 그래도 사람들이 열심히 하도록 격려하는 도전 · 보상 요소는 필요하다."

## 결론

| 정보 | 브라우저 게임 | 설치형 게임 |
| --- | --- | --- |
| 마지막으로 한 날 · 플레이 시간 | **플랫폼이 직접 앎** — 플레이 화면(PG06)이 게임을 감싸고 있어서 열고 닫은 시각을 기록 | **모름** — 받은 날 · 받은 버전만 앎 |
| 진행도(%) | 게임이 **SDK 로 알려 줄 때만** (`aDmD.progress(0.62)`) | 모름 |
| 저장(다른 기기에서 이어하기) | 게임 저장은 게임 자체(브라우저 저장소). 클라우드 저장은 SDK 로 선택 지원(L2) | 모름 · 게임 몫 |
| 게임 안 도전과제 | 게임이 **SDK 로 알려 줄 때만** (`aDmD.unlock("stage-10")`) — 대부분 안 쓸 것 | 없음 |

- 설치형은 실행 런처(Steam 같은 클라이언트)를 만들지 않는 한 실행 여부도 알 수 없다. 런처는 만들지 않는다(무료 · 보안 · 범위).
- SDK 는 **선택**이다. 안 써도 게임은 올라가고, 쓰면 진행도 · 도전과제 · 클라우드 저장이 생긴다. SDK 는 플레이 화면 iframe 과 `postMessage` 로만 이야기한다(게임 코드가 플랫폼 쿠키 · 계정에 접근하지 못함).

## 화면에 반영한 것 (PG01 이어하기)

- 이어하기 = **최근에 한 브라우저 게임**, 최근 순. 줄 아래 글: `어제 · 2시간 10분 플레이`.
- 진행 막대는 SDK 로 진행도를 알려 준 게임에만(`진행 62%`). 나머지는 막대 없음.
- 설치형은 플레이 기록이 없으므로 이어하기에는 **새 버전이 나왔을 때만** `설치형 · v1.3 받음 · 5일 전` + `업데이트` 버튼으로 나온다. 평소엔 라이브러리(PG14) `설치형` 탭에.
- 카드의 `도전과제 23/40` 표기는 뺐다.
- 아직 남은 곳: `PG07 플레이 종료`의 "진행 18/40 · 도전과제 7/12" 숫자, `PG14 내 라이브러리`의 진행 % — 같은 규칙(SDK 게임일 때만)으로 다음 묶음 검토 때 고친다.

## 도전 · 보상 — 따로 논의 (열린 질문)

게임 안 도전과제가 없어도 **플랫폼이 직접 셀 수 있는 것**으로 격려할 수 있다. 논의 때 고를 후보:

1. **플랫폼 도장** — "이번 주 새 게임 3개 해 보기", "첫 리뷰", "잼 작품 5개 플레이", "메이커 3명 팔로우". 브라우저 게임 · 리뷰 · 팔로우만으로 셀 수 있음. (기존 열린 질문 L2-1 고양이 도장과 합칠 수 있음)
2. **게임별 '끝까지 해 봄'** — 메이커가 정한 기준(플레이 시간 n분 또는 SDK 진행도 100%)을 넘으면 카드에 완주 표시.
3. **SDK 도전과제** — 쓰는 게임에서만 상세에 목록 표시. 플랫폼 보상과는 분리.
4. 보상의 형태 — 고양이 얼굴 꾸미기 아이템(S2 의 먼 미래 계획), 프로필 배지, 잼 투표권 등. **돈 · 포인트 환전은 하지 않는다**(무료 플랫폼).
