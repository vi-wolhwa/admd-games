# PlayGround 모바일 시안 (2026-11-26)

> 결정: PM1 탭바 확정 · **PM2 PC 전용 게임도 기본으로 보이고 표시만**(‘되는 게임만 보기’는 꺼진 상태로 제공) · PM3 반투명 버튼 2개 확정.

캔버스 `PG91 모바일 · 홈` · `PG92 모바일 · 게임`. 생성기 [`tools/ds-canvas/pg_mobile.py`](tools/ds-canvas/pg_mobile.py). 라이트 · 다크 확인, 얼굴은 고양이 실루엣.

## 구조

- **탭바**: 홈 · 게임 · 라이브러리 · 알림 · 나 — MakersGround 모바일과 같은 자리 규칙(3번째 = "내 것").
- **상단 바**: 로고 + PlayGround · 테마 전환 · 검색 · 알림(게스트는 로그인).
- **홈 순서**: v10 을 한 열로 — 배너(4:3, 아래 가림막 위 글자 · 넘김 점) → 이어하기(진행 막대 + 이어하기 버튼) → 이번 주 PICK(가로 넘김) → 주간 랭킹(옅은 쪽빛 상자, 4줄, 칩 탭) → 몇 분 있어요?(칩 + 2열) → 로그인 띠(게스트) → 전체 게임.

## 핵심: "이 휴대폰에서 되나"를 숨기지 않는다

R-SYS-09(모바일 = 탐색 · 라이브러리 · 터치 게임)를 화면 규칙으로:
1. **PC 전용 게임도 기본으로 보인다**(PM2 — 게임 수가 적은 초기에 풍성하게). "이 휴대폰에서 되는 게임만 보기" 스위치는 꺼진 채로 제공.
2. 카드에 **"PC 에서"** 표시(아트 오른쪽 위 실행 칩 자리).
3. 상세의 실행 조건 칩 맨 앞: 되면 비취 "이 휴대폰에서 돼요 · 가로", 안 되면 쪽빛 "PC 전용 · 키보드" + 안내 상자.
4. 안 되는 게임의 주 버튼은 **"PC 로 링크 보내기"**(내 다른 기기 알림으로 보냄 · 로그인 필요) — 저장하면 PC 라이브러리에 바로 보임.
5. 설치형도 모바일에서는 "PC 로"(Android 파일은 L2 검토).
