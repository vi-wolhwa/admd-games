사용자가 자리를 비운 동안(2026-11-26~) Claude 가 혼자 진행한 작업에서 **사용자 판단이 필요한 것**을 모은다. 돌아오면 이 문서부터 본다.
- 각 항목: 무엇을 · 추천안 · 다른 선택지 · 볼 곳(캔버스 페이지 / 문서).
- 결정되면 줄을 지우지 말고 "→ 결정:" 을 붙이고, 문서·캔버스에 반영한다.

## 2. 피드백을 받고 싶은 것 (디자인 — 되돌릴 수 있음)

| # | 무엇 | 내가 정한 것 | 확인하고 싶은 점 |
| --- | --- | --- | --- |
| F1 | 자모 얼굴 타일 12색 | 같은 휘도·채도 낮춘 차분한 톤(홍·주·귤·황·올리브·풀·비취·청록·하늘·쪽·보라·자두) | 더 선명한 게 좋은지, 이 톤이 좋은지 |
