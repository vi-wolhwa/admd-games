## PG-GAME 게임 상세 — 시안 A · B

첫 화면에서 판단할 3가지(R-DETAIL-03): **무슨 게임인지(움직이는 화면) · 지금 되는지(실행 조건) · 누가 만들었는지(메이커 얼굴)**.

| | A · 결정 패널 | B · 무대 |
| --- | --- | --- |
| 첫 화면 | 제목 줄(34px · 메이커 · 태그) → 왼쪽 미디어(16:9 + 썸네일 6, 마지막은 영상 자리) · 오른쪽 380 패널(상태별 버튼 · 실행 조건 6줄 · 추천률 · 메이커 + 팔로우) | 게임 대표색 전폭 무대: Gasoek 52 제목 · 한 줄 소개 · 메이커 · 실행 조건 칩 · 큰 플레이 버튼 / 오른쪽 큰 미디어 |
| 스크롤 | 탭(소개 · 리뷰 · 개발일지 · 업데이트) 고정 | 얇은 바(작은 그림 · 제목 · 탭 · 플레이 버튼) 고정 |
| 인상 | PC 사이트 · 정보 밀도 · 상태별 버튼이 명확 | 몰입 · 브랜드 · 게임이 주인공 |
| 추천 | **A** — 상태 5종(처음 · 진행 중 · 완료 · 다운로드 · 이 기기 불가)의 버튼과 정보를 한 패널에서 일관되게 바꿀 수 있고, 다운로드 파일 선택·검사 결과가 들어갈 자리가 있다 | B 의 게임색 무대는 PICK 게임에만 쓰는 특별판으로 남길 수 있음 |

A 의 상태별 패널(캔버스 Tweaks `state`):
- **처음**: 지금 플레이(56px) + 저장 · 친구에게 도전장.
- **진행 중**: 이어하기 · 23스테이지 + 진행 45% 막대 · 마지막 플레이 · 도전과제 n/m.
- **완료**: 다시 하기 + 완주일 · 총 시간 · 최고 기록 + 내 기록으로 도전장.
- **다운로드**: 플랫폼 파일 고르기(용량 · 형식 · 서명 여부) → 다운로드 버튼 → 검사 통과 띠(리포트 링크) → Windows 경고 안내 링크.
- **이 기기 불가**: QR + "휴대폰에서 열어 주세요" + 내 휴대폰으로 링크 보내기, 실행 조건도 "휴대폰 · 패드 전용"으로.

아래 공통: 소개(본문 16/1.8 + 특징 3줄 · 오른쪽 정보 표) → 리뷰(추천률 Gasoek 56 · 자주 고른 말 칩 · 리뷰 3열, 플레이 시간 표시 · 메이커 답글) → **만든 사람**(옅은 쪽빛 띠: 큰 얼굴 · 소개 · 팔로우 · 최근 일지 · 다른 게임) → 업데이트(버전 · 패치노트) → 비슷한 게임 레일 → 게임 신고.

## PG-PLAY 플레이 화면

- 다크 고정, 위 **48px 먹색 바 하나**(뒤로 · 로고 · 제목 · 메이커 얼굴 | 소리 · 조작 방법 · 문제 알리기 · 전체 화면 | 나가기 Esc 두 번). 나머지는 게임.
- 불러오는 중: 고양이 **놀람(o)** 얼굴 + 진행 막대 + 용량 숫자 + 조작 요령.
- 플레이 중: 게임 영역에 포커스 링, 처음 4초 "게임에 들어왔어요 · Esc 일시정지" 안내. 도전과제 토스트(L2)는 오른쪽 위.
- 일시정지(Esc): 계속하기 · 조작 키 · 소리 · 문제 알리기(환경 정보 자동 첨부) · 나가기(진행 저장됨).
- 오류: **시무룩(n)** + 원인과 할 일 + 다시 불러오기 · 문제 알리기 + **보내는 정보를 그대로 보여 줌**.

'끝은 다음의 시작'(시나리오 원칙 5). 게임색 결과 카드(Gasoek 72 기록 · 최고 기록 배지 · 진행/시간/도전과제 · 다음 스테이지/다시 하기) + 오른쪽 세 상자(한 번 눌러 끝나는 평가 + 태그 칩 · 메이커 팔로우 · 친구에게 도전장 링크) + 다음에 해 볼 게임 4개.

## PG-DL 다운로드 안내 · PG-SCAN 보안 검사 리포트

- 다운로드 뒤: "다운로드를 시작했어요" + 설치 3단계. **SmartScreen 경고 창 예시**에 누를 곳(추가 정보 → 실행)을 노랗게 표시하고, 서명이 없는 이유(인증서 비용)와 aDmD 가 대신 한 일(검사 · 지문)을 솔직히 설명.
- 리포트: "문제를 찾지 못했어요"(‘안전합니다’라고 단언하지 않음) · 검사 시각 · 파일별 SHA-256 · 엔진별 결과 · **네 가지 상태(통과 · 검사 중 · 주의 · 차단)** · 버전별 이력 · 검사가 하는 일/못 하는 일. 엔진 이름은 무료 검사 방식 결정(D4) 후.

## PG-LIB 내 라이브러리

얼굴 + 숫자 4개(플레이한 게임 · 저장 · 받은 설치형 · 이번 달 시간) → 탭(이어하기 · 저장함 · 다운로드함 · 플레이 기록) → 검색 + 정렬·필터 칩 → `LibraryRow`(진행 막대 · 마지막 플레이 · 총 시간 · **업데이트 있음** · 주 버튼 하나 · 더 보기) → 저장만 하고 안 한 게임 레일 → 다른 기기 안내.
