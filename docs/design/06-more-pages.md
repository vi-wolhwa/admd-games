# 공통 · MakersGround 추가 시안 — 로그인 · 내 얼굴 만들기 · 업로드 마법사 · 검색 (2026-11-26, 검토 대기)

생성기: [`tools/ds-canvas/pages3.py`](tools/ds-canvas/pages3.py). 결정 사항은 [feedback-queue.md](feedback-queue.md) S1~S3.

## SH-LOGIN 로그인 (모달)
- 페이지를 떠나지 않는 대화상자(440). 위에 **기쁨 표정 고양이**, 제목 "로그인하고 내 얼굴 만들기".
- 버튼 2개: Google · GitHub(비밀번호 없음 — Worker CPU 제한 때문이기도 함, ADR 0004).
- 옅은 그라운드 색 상자: "로그인 전에 한 기록은 그대로 옮겨져요 — 진행 2개, 저장 3개"(R-ACCT-03).
- 약관 동의는 한 줄 안내 + 링크, "광고용으로 정보를 쓰지 않아요".

## SH-ONBOARD 내 얼굴 만들기
- 왼쪽 420: **그라운드 색 면 위에 내 얼굴 168px** + 닉네임 + "리뷰 · 랭킹 · 헤더에 이렇게 나와요" 미리보기.
- 오른쪽: 닉네임(2~12자, 즉시 확인: "첫 글자 ‘ㅇ’ 이 눈이 돼요") → 눈 14 자음 → 입 6(ㅅ ㅁ ㅇ ㅂ ㅡ ㅗ) → 색 12(같은 밝기).
- 건너뛰기 = 닉네임 첫 자음 · ㅅ · 무작위 색으로 자동 생성.

## MG-UPLOAD 업로드 마법사
- 위: 로고 · "새 게임 올리기 · 제목" · **자동 저장됨 · 방금** · 닫기. 그 아래 8칸 단계 막대(지난 칸 흑연, 지금 칸 인주).
- 3단계 빌드: 끌어다 놓기 영역 → 올린 파일 + 진행 → **즉시 형식 검사 목록**(통과 ✓ 비취 / 주의 ! 인주 + 해결 방법 링크) · 오른쪽 엔진별 팁.
- 5단계 대표 그림: 큰 그림 위 자르기 손잡이 → 카드 16:9 · 공유 1200×630 · 정사각 아이콘 미리보기(안전 영역 점선) · 오른쪽 "이렇게 보여요" 실제 GameCard.
- 아래 고정: 이전 · "휴대폰에서 이어서" 안내 · 나중에 이어서 · 다음.

## PG-SRCH 검색 결과
- "‘픽셀’ 검색 결과" + 종류별 개수 → 밑줄 탭(전체 · 게임 · 메이커 · 개발일지 · 태그).
- 전체 탭: 게임 4열 → 메이커 카드 3 → 개발일지 줄. 검색어는 **옅은 강조색 형광펜**.
- 결과 없음: 졸린 고양이 + "한 글자 더 적어 보세요"(초성 검색 안내) + 제안 칩(R-SRCH-02).
