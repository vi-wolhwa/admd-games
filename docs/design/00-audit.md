# 기존 디자인(aDmD Ground 캔버스) 감사

- 대상: https://claude.ai/code/artifact/57ed3789-695b-4f2c-8ae6-b210fafc167d (2026-11-25 이전)
- 기준: 사용자 경험, aDmD 만의 차별화·특색 (킥오프: 만든 사람이 보이는 곳 · 고르는 재미 · 같이 노는 곳 · 신뢰). "다시 만드는 데 오래 걸린다"는 판단 근거로 쓰지 않는다.
- 근거: 캔버스 렌더 캡처(screenshots/), 페이지·컴포넌트 소스, docs/ 기획 문서 8종.

## 결론 (2026-11-26 개정 — 사용자 결정: 계승·발전)

**콘셉트는 계승하고, 실행(팔레트·표현층·밀도·게스트 동선)을 고친다.**

처음 판정은 "시각 언어와 홈 구조 교체"였다. 새 콘셉트 시안 3개(판·놀이터·크레딧, [01-concept-directions.md](01-concept-directions.md))를 만들어 비교한 결과, 바깥 비유에서 출발한 시안들이 기존 콘셉트보다 약했다. 다시 보니 기존 콘셉트의 뼈대 — **두 그라운드 한 체계(강조색 하나로 전환), 테두리 대신 표면 대비 + 상호작용 때만 떠오름, 의미에만 쓰는 색, 큐레이션 문맥(왕좌·신작·숨은 보석·순삭·대전), 상태 인식 상세, MakersGround 의 생태계 폭, 구체적 카피** — 는 킥오프의 차별점과 이미 맞닿아 있다. 문제는 콘셉트가 아니라 실행이었다:

1. 팔레트가 Tailwind 기본값(blue-600 `#2563EB`, orange-600 `#EA580C`, slate 계열, rose-600 `#E11D48`)이라 흔해 보임
2. 규칙은 있는데 표현층(얼굴·시그니처 순간)이 없음
3. 히어로가 아트를 흐림, 카드 정보 과밀, 메이커 존재감 약함
4. 게스트 첫 스크롤의 로그인 벽, MakersGround 첫 화면의 지표판

아래 항목별 표는 첫 판정 기록으로 남긴다. "교체"로 적힌 항목 중 브랜드·시각 언어, 홈 구조, 색 체계는 **"계승 + 교정"** 으로 읽는다. 교정 내용은 [02-concept-ground.md](02-concept-ground.md).

### 첫 판정 (참고)

기존 디자인은 정돈되어 있고 근거 문서도 꼼꼼하지만, 결과물은 "잘 만든 일반 게임 포털·관리 대시보드"다. 킥오프에서 고른 세 가지 차별점이 화면 구조에 드러나지 않고, 로고의 "DmD 얼굴" 외에는 이 사이트만의 얼굴이 없다.

## 실제 캔버스에서 추가로 확인한 것 (2026-11-26)

- **게스트 첫 화면**: 히어로 바로 아래에 "내 라이브러리"와 "프로필"이 블러 처리된 로그인 벽 두 개로 나온다. 처음 온 사람이 첫 스크롤에서 만나는 것이 "로그인하라"는 요구 — 게스트에게는 이 자리를 발견·플레이 동선으로 채워야 한다.
- **MakersGround 히어로**: "게임을 만드는 사람들의 작업실" + 빌드 올리기 / 커뮤니티 둘러보기 + 지표 4종 — 일반적 SaaS 랜딩 문법. 이벤트 카드(BIC 전시)는 실존 행사명을 씀 → 시안에서는 가상의 행사로 교체.
- **"정산" 메뉴**: 메이커 퀵액션에 정산이 있다. 결제·정산은 유료 결제 대행이 필요하고 1차 범위(무료 운영) 밖이므로 PRD 에서 명시적으로 제외 또는 후속으로 둔다.

## 기존 디자인에 없던 것 (킥오프로 새로 필요해진 것)

- 누구나 업로드: 업로드 마법사, 게임 관리, 심사 상태, 신고·운영자 도구
- 다운로드 게임: 플랫폼별 파일, 요구사양, **보안 검사 결과**
- 같이 노는 곳: 친구·초대, 멀티 대기실, 랭킹을 사람 중심으로
- 만든 사람이 보이는 곳: 메이커 프로필·개발일지가 플레이 동선 한가운데
- 모바일 1급 MakersGround
