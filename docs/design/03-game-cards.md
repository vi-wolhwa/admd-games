## 2. 카드가 표현해야 하는 상태

| 종류 | 상태 |
| --- | --- |
| 게임 자체 | 신작(공개 14일 이내) · 업데이트(7일 이내) · 잼 작품 · 콘텐츠 표시(공포·폭력 등) |
| 실행 | 바로 플레이(브라우저) · 설치형(플랫폼) · 둘 다 · **이 기기에서 불가**(예: 휴대폰인데 키보드 전용) |
| 신뢰 | 보안 검사 통과 / 검사 중 / 주의 / 차단 (설치형만) |
| 나와의 관계 | 저장함 · 플레이함 · 진행률 · 완료(도전과제 100%) · 설치형 받음 · 업데이트 있음 |
| 사람 | 메이커(항상) · 친구가 플레이 · 지금 n명 플레이/대기 |
| 표시 상태 | 기본 · 호버 · 키보드 포커스 · 누름 · 불러오는 중(스켈레톤) · 아트 없음(대체 아트) · 긴 제목 |

## 3. 모든 카드가 따르는 공통 규칙

리서치에서 채택한 핵심(번호는 research/03 의 아이디어 묶음):

1. **아트 위에 글자를 굽지 않는다** — 메이커 업로드 규칙. 배지·칩은 플랫폼이 정해진 자리에만 그린다(Steam·Poki·CrazyGames 공통 규칙).
2. **아트 위 자리 배정 (모든 카드 동일)**
   | 자리 | 들어가는 것 | 최대 |
   | --- | --- | --- |
   | 왼쪽 위 | 상태 배지 하나: 큐레이션 문맥 / 신작 / 업데이트 / 잼 | 1개 |
   | 오른쪽 위 | 실행 칩: 바로 플레이 · 설치형 · 휴대폰 · 패드 · 같이 · 검사 통과(방패) — 호버·포커스 시 aDmD 툴팁 | 아이콘 3개 |
   | 왼쪽 아래 | 메이커 자모 얼굴 | 1 |
   | 오른쪽 아래 | 빠른 플레이(호버 시, 브라우저 게임만) | 1 |
   | 아래 가장자리 | 진행 막대(내가 한 게임) | 1 |
3. **아트 비율은 16:9 하나** — 업로드 필수 커버(1920×1080)를 모든 카드가 잘라 쓴다. 정사각 아이콘은 선택 업로드, 없으면 16:9 가운데를 자른다.
4. **숫자는 표본이 쌓였을 때만** — 평점은 리뷰 10개 이상일 때 "추천 92% · 38" 형식. 플레이 수 같은 허영 지표는 카드에 쓰지 않는다(Roblox 가 큰 타일에서 접속자 수를 빼고 발견이 늘어난 사례). 예외: 같이 하기의 "지금 n명 대기"처럼 행동을 돕는 실시간 숫자.
5. **호버 = 움직이는 미리보기, 크기는 고정** — 400ms 머물면 스크린샷 3장이 번갈아 나온다(MVP 는 영상 없이 무료로). 카드가 커지며 옆을 미는 Netflix 식 확장은 쓰지 않는다. `prefers-reduced-motion` 과 사이트 설정 "움직임 끄기"면 정지 이미지.
6. **접근성** — 카드 전체를 `<a>` 로 감싸지 않는다. 제목 링크를 카드 전체로 늘리고(stretched link) 저장·참가 같은 보조 버튼은 그 위에 둔다. 아이콘 칩은 모두 글자 레이블을 가진다. 키보드 포커스 = 아트에 2px 그라운드 색 테두리.
7. **불러오는 중 · 아트 없음** — 스켈레톤은 같은 크기. 아트가 없으면 메이커가 고른 대표색 바탕 + 제목 + 고양이 귀 표식으로 대체 아트를 자동 생성.

## 4. 카드 7종

| 컴포넌트 | 쓰는 곳 | 크기 · 비율 | 정보 층 (우선순위) | 호버 · 포커스 | 쓰지 않는 것 |
| --- | --- | --- | --- | --- | --- |
| **GameCard** | 카탈로그, 시간별, 검색 결과, 태그, 메이커의 게임, 비슷한 게임, 플레이 종료 추천 | M(5열 ≈227px) · L(4열 ≈282px — 홈·카탈로그 기본) · 16:9 | 아트 → 제목 → 메이커 · 장르 · 한 판 n분 → (선택) 추천 % 또는 "친구 2명이 함" | 떠오름 + 스크린샷 순환 + 빠른 플레이 | 태그 나열, 플레이 수, 설명 문장 |
| GameCard · **잼 모드** | 잼 아케이드, 잼 결과 | M · 16:9 | + 잼 리본(잼 이름 · 순위/상) + 팀 얼굴들 + "평가 n개" | 같음 | 일반 평점(잼 점수와 혼동) |
| **PickCard** | 이번 주 PICK, 컬렉션, 메이커 대표작, 신작 공개 슬롯 | 296px · 16:9 아트, **배경 없음** | 문맥 배지 → 제목 → 메이커 → 이유 한 줄(사실만, 1인칭·큐레이터 표시 없음) | 떠오름 + 스크린샷 순환 | 평점, 플레이 수, 고른 사람 |
| **RankRow** | 주간 랭킹, 랭킹 페이지, 잼 결과 | 행 높이 64px · 16:9 썸네일 96px | 순위(Gasoek) → 등락 → 썸네일 → 제목 → 메이커 → 기준 지표 한 개 | 바탕 밝아짐 + 그림자 | 장르·태그 |
| **ContinueCard** | 이어하기(홈 회원), 라이브러리 상단 | L · 16:9 | 아트(+업데이트 배지) → 진행 막대(아트 밖) → 제목 → "어제 · 도전과제 7/8" → **이어하기 버튼** | 버튼 강조 | 메이커 얼굴(내가 이미 앎) |
| **MiniRow** | 검색 자동완성, 알림, 일지 본문 속 게임 언급 | 행 48px · 16:9 썸네일 64px | 썸네일 → 제목(검색어 강조) → 메이커 · 실행 방식 | 바탕 밝아짐, 화살표 키 이동 | 배지 |
| **LibraryRow** | 내 라이브러리, 설치형 관리 | 행 80px · 16:9 썸네일 128px | 썸네일 → 제목 · 메이커 → 진행·플레이 시간 → (설치형) 버전 · 용량 · 검사 결과 · **업데이트 있음** → 주 버튼(플레이/이어하기/다운로드/업데이트) | 바탕 밝아짐 | "설치됨"(웹은 실제 설치를 알 수 없어 "받은 버전"으로 표시) |
| **RoomCard** | 같이 하기 방 목록, 홈의 "지금 같이" | 280px · 16:9 아트 띠 | 게임 → 방 이름 · 방장 얼굴 → **대기 3/4명** + 참가자 얼굴 → 참가 버튼 | 참가 버튼 강조 | 카드 전체 클릭으로 입장(실수 방지 — 명시적 버튼만) |

## 5. 결정이 필요한 것 (A등급)

| 질문 | 추천안 | 이유 |
| --- | --- | --- |
| 호버 미리보기 영상을 받을 것인가 | **MVP 는 영상 없이 스크린샷 3장 순환**, 영상은 저장 비용 검토 후 | 스크린샷은 어차피 필수 업로드라 추가 비용 0. 영상은 저장소 용량·전송량 검토 필요 |
| 친구 활동("친구 2명이 함") 공개 기본값 | **기본 비공개**, 사용자가 켜면 공개 | 플레이 기록은 개인정보 성격 |


## 6. 적용 현황

- 캔버스 `게임 카드 컴포넌트` — 7종 · 상태 변형 · 공통 구조 해부도
- 캔버스 `PlayGround v10` 홈(문구·툴팁 수정, PICK 배경 제거, 전체 게임 4열) — PickCard(고른 게임) · RankRow(랭킹) · ContinueCard(이어하기, 회원) · GameCard(시간별 · 전체 게임). RoomCard·LibraryRow·MiniRow 는 해당 페이지(같이 하기 방 목록, 라이브러리, 검색) 디자인 때 적용.
