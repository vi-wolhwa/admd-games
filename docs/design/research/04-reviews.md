# 04. 리뷰 컴포넌트 — 선례 조사와 aDmD 설계 (2026-11-27)

계기: PG05 리뷰가 "가독성이 없고 구조가 이상하다"는 사용자 피드백. 리뷰 한 개를 **누가 · 어떤 맥락에서 · 무엇을 · 다른 사람에게 도움이 됐는지 · 메이커가 어떻게 답했는지**의 순서로 읽히게 다시 설계한다.

## 1. 선례

| | Steam | Google Play | App Store | itch.io |
| --- | --- | --- | --- | --- |
| 글쓴이 | 왼쪽 세로 칸: 아바타 · 이름 · 보유 게임 수 · 쓴 리뷰 수 | 아바타 · 이름 한 줄 | 이름 · 날짜 | 이름 · 날짜 |
| 판정 | 리뷰 맨 위 큰 띠 "추천 / 비추천" + 엄지 | 별점 | 별점 | 별점(선택) |
| 맥락 | **플레이 시간(총 · 리뷰 쓸 때)**, 게시일, 무료로 받음 · 얼리 액세스 표시 | 날짜 | 날짜 · 버전 | 날짜 |
| 본문 | 긴 글을 접고 "더 읽기" | 몇 줄 뒤 접힘 | 제목 + 본문 접힘 | 그대로 |
| 반응 | "도움이 되었나요? 예 · 아니요 · 재미있음 · 상" + "n명에게 도움됨" | "도움이 되었나요? 예 · 아니요" + n명 | 도움됨 | 없음 |
| 신고 | 메뉴 안 | ⋮ 메뉴 안 | 길게 누르기 | 메뉴 |
| 개발자 답글 | 본문 아래 접힌 상자 | 본문 아래 들여쓴 상자 · 날짜 | 들여쓴 상자 | 댓글 |
| 거르기 | 최근/전체 · 언어 · 플레이 시간 · 구매 경로 | 별점 · 기기 | — | — |

배울 점
- **맥락 정보가 신뢰를 만든다** — Steam 의 "리뷰 쓸 때 0.4시간"은 성의 없는 리뷰를 걸러 보게 한다.
- **신고는 메뉴 안에 숨긴다** — 모든 리뷰에 '신고' 글자가 보이면 소음이 되고 공격적인 인상을 준다.
- **도움됨은 숫자로 쌓인다** — 정렬 기준이 되고, 좋은 리뷰가 위로 온다.
- **본문 가독성** — 16px 안팎 · 줄 간격 1.7 · 한 줄 70자 안쪽 · 긴 글 접기.

## 2. aDmD 리뷰 아이템 (ReviewItem)

```
[고양이 얼굴 40] 새벽코딩                                  [⋯]  ← 메뉴: 신고 · (내 리뷰면) 고치기 · 지우기
                 리뷰 12개 · 👍 추천함
플레이 3.2시간 (쓸 때 1.1시간) · v1.1 에서 씀 · 11월 21일          ← 맥락 한 줄, 작은 회색
[짧고 굵음] [힌트가 친절해요]                                      ← 글쓴이가 고른 말(태그)
본문 — 16px · 줄 간격 1.75 · 최대 5줄, 넘치면 "더 보기"
[👍 도움이 됐어요 · 12]                                           ← 토글 버튼, 누르면 쪽빛 · 숫자 +1
┃ 픽셀상점 · 메이커 답글 · 11월 22일 · v1.2 에서 고침               ← 들여쓴 상자, 왼쪽 쪽빛 선
┃ 답글 본문
```

| 결정 | 이유 |
| --- | --- |
| 판정 띠 없음, 추천했으면 `추천함` 작은 표시만 | ADR 0009 — 싫어요 없음. 판정이 리뷰의 주인공이 아니라 본문이 주인공 |
| 플레이 시간 = 지금 · 쓸 때 둘 다 | 브라우저 게임은 플랫폼이 시간을 앎. 설치형은 모르므로 `다운로드함` 으로 표시 |
| 쓴 버전 표시 | 인디 게임은 업데이트가 잦다. "튜토리얼이 길어요"가 v1.1 얘기인지 알아야 메이커 답글("v1.2 에서 고침")이 의미가 있다 |
| 도움이 됐어요 = 긍정 하나만 | 싫어요 없음 원칙과 같은 이유. '아니요'가 없으니 정렬은 도움 수 + 최신 |
| 신고는 ⋯ 메뉴 | 드문 행동. 눈에 띄면 소음 |
| 목록은 한 열 · 최대 720px | 두세 열 카드는 줄 길이가 들쭉날쭉해 읽기 어렵다(이전 시안의 문제) |
| 오른쪽에 요약 · 거르기 · 쓰기 | 소개 탭과 같은 두 칸 구조 — 탭을 바꿔도 화면 골격이 그대로 |

## 3. 권한 (ADR 0009 보강)

- **추천 · 리뷰 · 도움이 됐어요 = 로그인한 사람만.** 게스트에게는 같은 자리에 `로그인하고 추천하기` 를 보여 주고 누르면 로그인 대화상자(SH01).
- **추천 · 리뷰는 이 게임을 해 본 사람만** — 브라우저 게임은 한 번 이상 실행, 설치형은 다운로드 기록. 이유: 공개 숫자라 조작을 막아야 하고, 해 보지 않은 사람의 평가는 메이커에게 도움이 안 된다. 해 보지 않았으면 버튼은 보이되 누르면 "먼저 한 판 해 보세요" 안내.
- 메이커 본인은 자기 게임에 추천 · 리뷰 불가(답글만).
