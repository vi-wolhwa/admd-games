# MakersGround = 커뮤니티 — 구조 결정 (2026-11-26)

## 사용자 결정 (M1 · M3)

- **M1**: 홈은 시안 B(일지 먼저)를 바탕으로 하되 **홈에 '내 게임'은 보여 주지 않는다.** MakersGround 의 목적은 **사람들끼리 자유롭게 소통하는 커뮤니티**다 — 개발일지 · 질문뿐 아니라 사소한 이야기까지. 홈 외에 **게시판들이 모인 커뮤니티 페이지**가 있어야 하고, 게시판은 처음부터 많지 않게, 필요에 따라 늘린다(구성은 Claude 판단).
- **M3**: **모바일에는 게임 업로드 UI 를 만들지 않는다.** 기술적으로 막는 게 아니라, 모바일 화면에 업로드 화면을 두지 않는 것. 업로드는 PC 에서.

## Claude 판단 (M2 · M4 · 게시판) — 사용자 위임

### 메뉴 (M2)
**홈 · 커뮤니티 · 내 게임 · 잼** (+ 오른쪽 "게임 올리기" 버튼, 알림, 얼굴).
- 개발일지 · 질문은 메뉴가 아니라 **커뮤니티 안의 게시판**. 메뉴가 늘지 않고 "커뮤니티가 중심"이 메뉴에서도 읽힌다.
- 내 게임은 홈에서 빠졌으니 메뉴에 둔다(관리 · 통계 · 보완 요청).
- 잼은 출시 후 기능(L2) — 잼이 열려 있을 때만 메뉴에 보인다.

### 게시판 (처음 5개 + 공지)

| 게시판 | 말머리 | 성격 | 특이 기능 |
| --- | --- | --- | --- |
| **자유** | 잡담 · 정보 · 고민 | 무엇이든. 커뮤니티의 기본 | 홍보 글은 한 달에 한 번 |
| **개발일지** | — | 게임에 연결된 글. PlayGround 상세 · 메이커 페이지 · 팔로우 소식에 노출 | 게임 연결 필수, 이번 주 일지 PICK |
| **질문** | 엔진 · 아트 · 사운드 · 웹 빌드 · 운영 | 묻고 답하기 | 답변 채택 → "해결" |
| **피드백** | — | 스크린샷 · GIF · 빌드 링크를 올리고 의견 묻기 | 그림 목록 보기, **간단 투표**(A/B) |
| **팀원 모집** | 역할 | 같이 만들 사람 찾기 | 모집 중 / 마감 |
| 공지 | — | 운영 | 각 게시판 맨 위 고정 |

**늘리는 규칙**
1. 새 주제는 먼저 **말머리**로 시작한다(게시판보다 가볍다).
2. 한 말머리 글이 **한 달 동안 주 20개 이상**이면 게시판으로 독립시킨다(예: 자유/정보 → "정보" 게시판).
3. 사용자는 자유 게시판에 "제안" 으로 새 게시판을 요청할 수 있다. 운영자가 판단.
4. 한 달에 글이 10개 미만인 게시판은 합친다. 메뉴에 게시판이 7개를 넘지 않게.

### 게스트 첫 화면 (M4)
**홈에는 얇은 인주 띠 한 줄**("만들고, 묻고, 수다 떠는 곳 — 게임을 올리지 않아도 누구나 글을 쓸 수 있어요" + 처음 올리는 분 · 로그인하고 글쓰기)만 둔다. 커뮤니티가 목적이니 게스트도 바로 글을 보게 한다.
"올리면 이렇게 보여요" 카드 미리보기는 홈에서 빼고 **처음 올리는 분 안내(MG-START)와 업로드 마법사 5단계**(이미 있음)로 옮긴다.

## 시안 (캔버스)

| 페이지 | 내용 |
| --- | --- |
| `MakersGround 홈 C` | 지금 커뮤니티(게시판 칩 + 섞인 최신 글 9) · 오늘 많이 본 글 6 → 이번 주 일지 PICK → 피드백을 기다리는 작업(그림 4열 · 투표 막대) → 새 개발일지(띠) → 질문 · 팀원 모집 → 이번 주 공개된 게임 → 잼. 내 게임 없음 |
| `커뮤니티 목록` | 게시판 밑줄 탭(개수) → 말머리 칩 · 정렬(최신 · 인기 · 댓글 많은) · 게시판 안 검색 → 공지 고정 → **한국 커뮤니티식 표 목록**(말머리 · 제목[댓글] · 글쓴이 얼굴 · 날짜 · 조회 · 좋아요) → 쪽 번호 → 게시판 규칙 |
| `커뮤니티 글 보기` | 820px 한 열 · 17px 본문 · 그림 2장 · 투표 · 게임 링크 카드 · 좋아요 · 저장 · 댓글(글쓴이 · 메이커 표시, 답글 한 단계) · 같은 게시판 다른 글 |
| `MakersGround 모바일` (개정) | 탭바 **홈 · 커뮤니티 · 내 게임 · 알림 · 나**(모두 같은 모양) · 글쓰기는 떠 있는 버튼 · 내 게임 화면에서 그림 · 빌드는 "PC 에서 할 수 있어요 · PC 로 링크 보내기" |

`MakersGround 홈 A` · `홈 B` 는 비교 기록으로 남긴다(채택 안 함).
