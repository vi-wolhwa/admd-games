# 추가 시안 2 — 전체 게임 · 프로필 · 알림 · 설정 · 처음 올리는 분 · 글쓰기 · 지난 PICK (2026-11-26)

생성기: [`tools/ds-canvas/pages5.py`](tools/ds-canvas/pages5.py) · [`pages6.py`](tools/ds-canvas/pages6.py). 모두 라이트 · 다크 확인, 얼굴은 고양이 실루엣.

| 캔버스 페이지 | ID | 핵심 |
| --- | --- | --- |
| `전체 게임` | PG-CAT | 사이드바 없이 **위쪽 필터 상자**(장르 · 한 판 · 실행 · 인원, 칩 여러 개 선택) → 적용된 조건 칩(✕) · 정렬(추천 · 최신 · 평가 · 짧은 순) → 4열 카드 → **‘더 보기’ 버튼**(무한 스크롤 없음). **결과가 적을 때**(R-DISC-04): 큰 가로 카드 + "조건을 조금 넓혀 볼까요?" 칩(‘같이’ 빼면 +30 등) |
| `공개 프로필` | PG-PROFILE | 큰 고양이 얼굴 120 · 닉네임 · 소개 · 리뷰/팔로우 수 · 친구 신청. **칸마다 누구에게 보이는지 표시**(최근 플레이 = 친구에게만). 리뷰 · 팔로우 메이커는 공개, 도전과제는 L2 |
| `알림` | SH-NOTI | 헤더 종 → 400px 패널(전체 · 내 활동 · 팔로우 · 친구 탭, 새 알림 = 옅은 그라운드 바탕 + 점, 누가 했는지 얼굴 + 종류 아이콘 + 관련 그림) · 전체 페이지(오늘 / 이번 주, 30일 후 자동 삭제) |
| `설정` | SH-SETTINGS | 사이드바 대신 **위 고정 탭 + 한 페이지 스크롤**: 프로필 · 계정 연결(Google · GitHub) · 알림 · 공개 범위(지금 하는 게임 기본 켜짐 · 친구에게만, 라이브러리 모두/친구만/나만) · 화면(라이트 시작 · 다크 · 기기 설정, 움직임 줄이기) · 데이터(JSON 내려받기 · 탈퇴) |
| `처음 올리는 분` | MG-START | Gasoek 제목 + **‘올리면 이렇게 보여요’ 카드 미리보기(M4)** → 올릴 수 있는 것(웹 200MB · 설치형 500MB) → 공개까지 4단계(보통 이틀 · 운영자 승인) → 지켜 주세요(✓ / !) → 자주 묻는 것. 버튼은 "PC 에서 첫 게임 올리기" |
| `글쓰기 · 개발일지` | MG-LOG 작성 | 게시판 · 게임 연결 · 말머리 선택 → 큰 제목 → 고정 도구 막대 → 글자 그대로 보이는 본문(그림 블록 · 설명) → 어디에 실리는지 안내 → 아래 고정(글자 수 · 미리보기 · 임시 저장 · 올리기). 커뮤니티 모든 게시판이 같은 에디터, **휴대폰에서도 글쓰기는 가능** |
| `지난 PICK · 컬렉션` | PG-ISSUE · PG-COLL | 주제 컬렉션(겹친 카드 그림) → 주간 PICK 보관함(Gasoek 주 이름 · 한 줄 주제 · 카드 4 + 이유 한 줄, ‘누가 골랐다’ 없음) |

남은 페이지(나중): 잼(L2) · 랭킹 전체(L2) · 친구 · 같이 하기 대기실(L2) · 리뷰 전체 · 고객센터/약관 · 운영(신고 · 큐레이션 편집 · 공지) · **모바일 PlayGround(별도 디자인)**.
