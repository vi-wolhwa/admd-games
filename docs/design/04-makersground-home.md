# MakersGround 홈 — 시안 A · B · 모바일 (2026-11-26, 사용자 검토 대기)

사용자가 자리를 비운 동안 확정된 PlayGround v10 문법과 [디자인 시스템](system/README.md) 위에서 혼자 만든 시안. **결정은 사용자** — [feedback-queue.md](feedback-queue.md) M1~M4.

캔버스: `MakersGround 홈 A` · `MakersGround 홈 B` · `MakersGround 모바일` (Tweaks: `startSignedIn` 게스트/회원 · `theme` · `showMemo` 설명 메모). 생성기: [`tools/ds-canvas/mg.py`](tools/ds-canvas/mg.py), [`mg_mobile.py`](tools/ds-canvas/mg_mobile.py).

## 1. 출발점

- 기존 MakersGround v2 의 문제(00-audit M-1~M-6): **첫 화면이 지표판**, 패널 20여 개, SaaS 랜딩 히어로("게임을 만드는 사람들의 작업실"), 등급·기여도 게이지, 모바일 미고려.
- 요구사항: R-MK-01(처음 온 메이커 안내), R-MK-06~07(상태 단계 · 모바일 확인·간단 수정), R-MK-10~13(내 게임·리뷰·제보), R-COMM-01·05(개발일지), L2: 질문·모집·잼.
- 지킨 규칙: 헤더 한 줄 · 사이드바 없음 · 흰 바탕 + 여백 · 인주는 각인 장치에만 · 카드 바탕색 없음 · 허영 지표 없음(내 게임 숫자는 **본인에게만 보이는 행동용 숫자**라 허용) · 한국어 자연스러운 말.

## 2. 공통 골격

- 헤더: 로고(귀 인주) + `MakersGround` · 메뉴 **홈 · 내 게임 · 개발일지 · 질문 · 잼** · 그라운드 전환(메이커스 칸 인주) · 검색(게임·메이커·글) · **게임 올리기**(주 버튼) · 알림 · 얼굴. 게스트는 로그인 + 게임 올리기.
- 공통 섹션: 개발일지(옅은 인주 띠) · 이번 주 공개된 게임(레일) · 답을 기다리는 질문 + 팀원 모집(두 열 목록) · 잼 D-day(먹 띠) · 푸터(처음 올리는 분 · 심사 기준 · PlayGround 로).
- 게스트 첫 화면(A): **"만든 게임, 여기에 올려 보세요"**(Gasoek 40) + 올리는 법 3단계 + 버튼 2개 + "무료 · 보안 검사 무료 · 언제든 비공개" + 오른쪽 **"올리면 이렇게 보여요"** 카드 미리보기. 숫자로 설득하지 않고, 결과물(PlayGround 카드)을 먼저 보여 준다.

## 3. 시안 비교

| | A · 작업 먼저 | B · 일지 먼저 |
| --- | --- | --- |
| 회원 첫 화면 | **할 일 3**(보완 요청 · 새 리뷰 · 버그 제보, 각 줄에 버튼) + 바로 하기(올리기 · 새 버전 · 일지 쓰기) → **내 게임** 줄 목록(상태 칩 · 단계 · 7일 플레이 막대 · 추천률 · 새 리뷰 · 제보 · 버튼) | **내 게임 한 줄 띠**(게임별 작은 그림 + 상태 칩, "할 일 3", 올리기) → **이번 주 일지 PICK**(큰 그림 + 요약 + 게임 플레이 버튼) → 새 개발일지 4열(칩 필터) |
| 게스트 첫 화면 | 소개 + 3단계 + 카드 미리보기 | 인주 띠 한 줄("만든 게임, 여기에 올려 보세요" + 버튼) |
| 인상 | 도구 · 작업 공간. 들어오면 할 일이 바로 보임 | 커뮤니티 · 매거진. 동료의 작업에 자극받음 |
| 약점 | 일지·커뮤니티가 한 화면 아래로 밀림 | 할 일을 보려면 한 번 더 눌러야 함, 게임이 없는 신규 메이커에겐 띠가 비어 보임 |
| 추천 | **A** — 메이커가 MakersGround 에 오는 첫째 이유는 "내 게임 확인·처리". 초기엔 일지 수가 적어 B 의 주인공이 비기 쉽다. B 의 **일지 PICK** 은 A 의 개발일지 띠 맨 앞 칸으로 가져올 수 있다 |

## 4. 모바일 (1급)

- 탭바: **홈 · 내 게임 · [＋ 올리기] · 일지 · 나** — 올리기는 가운데 큰 버튼(52, 인주). 누름 영역 44 이상.
- 메이커 홈: 할 일 → 내 게임(가로 넘김 카드) → 개발일지 목록(글 왼쪽 · 그림 오른쪽).
- 게스트 홈: Gasoek 30 소개 + 3단계 + 전폭 버튼.
- **게임 상태 · 보완 요청**(R-MK-07): 세로 단계(작성 ✓ → 자동 검사 ✓ → 심사·보완 요청 ● → 공개 ○), "고칠 것 1개" 상자, 스크린샷 추가 칸, **다시 제출**, 휴대폰에서 바로 고칠 수 있는 항목(한 줄 소개 · 공개 설정 · 태그).
