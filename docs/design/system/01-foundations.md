# 01 · 기초 토큰

값의 원본은 [`tokens.css`](tokens.css) 다. 이 문서는 **왜 그 값인지, 언제 쓰는지**를 적는다.
확정된 홈(캔버스 `PlayGround v10`)에서 뽑아 정리했고, v10 과 어긋나던 몇 곳은 시스템 쪽으로 맞췄다(맨 아래 "v10 대비 정리").

## 0. 3층 구조

| 층 | 어디에 | 예 | 규칙 |
| --- | --- | --- | --- |
| 원시 | `@theme` | `--color-jjok-500`, `--radius-lg` | 이름 붙은 값. **화면 코드에서 원시 색을 직접 쓰지 않는다**(`bg-jjok-500` ✗) — 예외: 자모 얼굴 타일색 |
| 의미 | `:root` 변수 + `@theme inline` | `--sunken` → `bg-sunken`, `--accent` → `bg-accent` | 테마(라이트·다크)와 그라운드(play·make)에 따라 값이 바뀐다 |
| 컴포넌트 | `:root` 변수 | `--btn-h`, `--pick-w`, `--z-tooltip` | 크기·모양·순서. 컴포넌트 CSS 안에서만 |

- 테마: `<html data-theme="light|dark">`, 없으면 OS 설정(`prefers-color-scheme`)을 따른다. **MVP 는 라이트만(ADR 0008)** — 구현 땐 `<html data-theme="light">` 로 고정하고 다크 토큰은 남겨 둔다.
- 그라운드: `<html data-ground="play|make">`. 한 화면 안 일부만 다른 그라운드로 칠할 때도 그 요소에 `data-ground` 를 단다.
- Tailwind 기본 팔레트·글자 크기·그림자·반경은 `initial` 로 지웠다. `text-xl`, `shadow-md`, `bg-blue-600` 은 만들어지지 않는다 — 실수로 기본값을 쓰는 것을 막는다.

다크 모드 원칙: **채움색은 라이트와 같고**(브랜드가 테마에 따라 바뀌지 않게), 바탕 위 글자로 쓸 때만 400 톤으로 올린다. 구현: 테마가 `--dark: 0|1` 을 정하고, 강조 토큰(`accent-text`, `accent-tint`)은 `:root, [data-ground], [data-theme]` 마다 `color-mix(… calc(var(--dark)*100%) …)` 로 다시 계산한다 — 다크 안의 라이트 섬, PlayGround 안의 인주 띠가 섞여도 맞게 풀린다. 다크 대비 확인 — 강조 글자 400 은 바탕 6.2~6.4:1, sunken 5.3:1, 옅은 바탕 5.0:1 이상.

### 1.3 색 쓰는 규칙
1. UI 는 흑연 + 그라운드 강조색 **하나**. 의미색(비취·다홍)은 상태에만.
2. 큰 색면은 **게임 아트의 대표색**(배너)과 그라운드 띠(랭킹·로그인) 두 종류뿐. 카드 바탕색 금지.
3. 강조색은 [02-brand.md §3 그라운드 각인 장치](02-brand.md#3-그라운드-색-각인)에만. 장식용으로 아무 데나 칠하지 않는다.
4. 색만으로 뜻을 전하지 않는다 — 등락은 ▲▼, 검사 결과는 방패 아이콘 + "검사 통과".

- 서체: **Pretendard Variable**(본문·UI, OFL, 자체 호스팅 woff2) + **Gasoek One**(디스플레이, OFL, Google Fonts). 다른 서체 추가 금지.
- **Gasoek One 은 28px 이상, 한 화면 2~3곳**(배너 · 순위 숫자 · D-day). 작은 라벨에 쓰면 안 읽힌다(사용자 피드백).
- 굵기 4단: 400 / 600 / 700 / 800. 900 은 쓰지 않는다.
- 숫자는 `tabular-nums`(진행률, 순위, 시간). 한국어 줄바꿈은 `word-break: keep-all`, 제목은 `text-wrap: balance`.
- 최소 크기: 문장 13px, 본문 15px. 12px 는 굵은 짧은 낱말에만.

## 3. 간격

4px 단위(`--spacing: 4px`, `p-4` = 16px). 자주 쓰는 값만 쓴다:

| 값 | 쓰는 곳 |
| --- | --- |
| 2 · 4 · 6 | 아이콘과 글자, 메타 줄 사이 |
| 8 · 10 | 아트 위 자리 여백(작은 카드 8, 큰 카드 10), 칩 사이 |
| 14 · 16 | 레일 카드 사이 16, 랭킹 줄 안쪽 |
| 18 | 섹션 제목 → 내용 (`--section-head-gap`) |
| 20 · 24 | 3열 그리드 20, 4열 그리드 가로 24 |
| 28 · 36 | 헤더 요소 사이 28, 4열 그리드 세로 36 |
| 44 · 48 | 띠 안쪽 위아래 |
| **64** | 섹션 사이 (`--section-gap`) |
| 88 | 마지막 섹션 → 푸터 |

그리드: PC 본문 1200px, 한 열(사이드바 없음). 레일 16, 3열 20, 4열 24×36, 5열 16.

## 5. 그림자 · 높이

평면이 기본이다. 그림자는 **움직이는 것과 떠 있는 것**에만.

| 토큰 | 값 | 쓰는 곳 |
| --- | --- | --- |
| `hairline` | `0 1px 2px rgb(21 26 32/.08)` | 선택된 탭(옅은 띠 위) |
| `chip` | `0 4px 10px -4px rgb(0 0 0/.45)` | 아트 위 배지 |
| `float` | `0 6px 16px -6px rgb(0 0 0/.5)` | 빠른 플레이 버튼 |
| `lift` | `0 12px 26px -12px` 라이트 `.36` / 다크 `.7` | 호버로 3px 들린 아트·랭킹 줄 |
| `pop` | `0 12px 28px -10px rgb(0 0 0/.5)` | 툴팁, 메뉴, 대화상자 |

쌓임 순서: 아트 위 자리 3 → 호버 카드 6 → 호버 칩 8 → 헤더 20 → 툴팁 30 → 드롭다운 40 → 대화상자 50 → 토스트 60.

## 6. 모션

- 곡선 하나: `ease-soft` = `cubic-bezier(.2,.7,.2,1)` (빨리 출발해 부드럽게 멈춤).
- 시간: 120ms(색, 툴팁) · 180ms(배경, 빠른 플레이 등장) · 240ms(아트 들림) · 260ms(표정 바꿈). 툴팁은 120ms 기다렸다가 뜬다.
- 움직이는 것: 호버 들림(−3px), 빠른 플레이 등장(아래서 6px, 90% → 100%), 스크린샷 순환(3.6s), **고양이 얼굴**(9s 주기 눈 굴리기, 플레이 호버 시 장난 표정).
- 자동 회전·자동 재생 없음(배너도 수동). `prefers-reduced-motion: reduce` 면 모든 시간이 0 이고 고양이도 멈춘다.

## 7. 아이콘

- **16 격자에 직접 그린 선 아이콘**: 선 1.7px, 둥근 끝·둥근 이음, 채움 없음(플레이·왕관·반짝·보석·달·저장됨만 채움). 표시 크기 12(배지) · 14(메타 줄·칩) · 16(버튼) · 20(헤더).
- 지금 17개: 브라우저 · 설치 · PC · 휴대폰 · 패드 · 같이 · 방패 · 플레이 · 왕관 · 반짝 · 보석 · 시계 · 달 · 말풍선 · 상승 · 저장 · 저장됨 (원본: 캔버스 `PlayGround v10` 의 `<symbol>`).
- 구현은 이 세트를 Svelte 컴포넌트로 옮긴다. 더 필요하면 Lucide(ISC)에서 가져와 16 격자·1.7px 선으로 맞춘다.
- 아이콘만으로 뜻을 전하지 않는다 — 글자 또는 `aria-label` 필수.
