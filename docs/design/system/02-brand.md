# 02 · 브랜드 장치

aDmD 의 정체성은 **조용한 흑연 화면 위에서 얼굴만 움직이는 것**이다. 장치는 네 가지 — 고양이 DmD(브랜드 얼굴), 자모 얼굴(사람 얼굴), 그라운드 색 각인, 게임색 필드. 그림 견본: 캔버스 `aDmD 고양이 얼굴`, `디자인 시스템 · 기초`.

## 1. 고양이 DmD

### 1.1 구조
```
 a  ⌒∧＿∧⌒        ← 귀·이마 윤곽 (SVG 한 줄, 그라운드 강조색)
    D m D         ← D 두 개 = 눈, m = 입(.72em)
```
- 표기는 항상 `aDmD`. `a` 는 얼굴 밖. 귀는 `DmD` 만 감싼다.
- 귀 SVG: `viewBox 0 0 64 20`, 경로 `M3 19 L8 2 L20 10 Q32 6 44 10 L56 2 L61 19`, 선 2.4px(로고) · 3px(큰 그림), 둥근 끝, `vector-effect: non-scaling-stroke`. 위치 `left:-.1em; top:-.21em; width:calc(100% + .2em); height:.46em`.
- 귀 색 = 그라운드 강조색(`--accent`). 푸터·비활성 자리에서는 `ink-4`.
- 글자: Pretendard 800, 행간 1, 자간 -0.02em. 최소 크기 18px(푸터) — 그보다 작으면 귀 없이 글자 `aDmD` 만.

### 1.2 표정 (D 를 돌려서 만든다)

| 표정 | 눈(D) | 입 | 언제 |
| --- | --- | --- | --- |
| 기본 | 똑바로 | m | 로고, 평소 |
| 장난·기쁨 | −90° (위로 웃는 눈) | w | 플레이 버튼 호버, 저장, 업적, 심사·검사 통과 |
| 시무룩 | +90° (아래로) | n | 404, 오류, 실행 실패 |
| 놀람 | 똑바로 × 1.12 | o | 로딩, 새 알림 |
| 졸림 | 세로 18% (납작) | z | 점검, 빈 상태 |

- 전환: `transform` 만, 260ms `ease-soft`, 눈 회전 중심 `50% 55%`. 두 눈은 60ms 차이로 따라 돈다.
- **한 화면에 얼굴 하나**(헤더 로고 또는 상태 화면 그림). 둘 이상 동시에 표정을 짓지 않는다.
- 표정은 **상태가 바뀔 때만** 바뀐다. 의미 없는 장식 애니메이션 금지.

### 1.3 저절로 움직이기
- 로고는 9초마다 한 번 눈을 흔들고(−14° → 12°) 잠깐 장난 표정(−90°, 입 w)을 지었다 돌아온다. 두 번째 눈은 60ms 늦게.
- `[data-play]` 요소(플레이 버튼, 빠른 플레이)에 호버하면 로고가 장난 표정으로 바뀐다 — "같이 신난다".
- `prefers-reduced-motion` 이면 대기 동작 없음, 호버 표정 전환은 즉시.

### 1.4 쓰지 않는 것
D 를 기본으로 기울이기, 귀를 채움색으로 칠하기, 고양이를 일러스트로 확장(몸·꼬리), 로고 색을 무지개·그라데이션으로, 얼굴 위에 말풍선 대사.

## 2. 자모 얼굴

모든 사람의 기본 프로필. 사진이 없어도 모두에게 얼굴이 있다.

### 2.1 만드는 법 (S2 개정 2026-11-26)
- **얼굴 틀 = 고양이 얼굴 실루엣**(둥근 머리 + 뾰족한 귀 두 개, 로고 귀와 같은 비례). 사각 타일을 쓰지 않는다. 구현: 색은 `--f` 변수, 모양은 SVG 마스크([`tools/ds-canvas/cat_face.py`](../tools/ds-canvas/cat_face.py) 의 `CAT_PATH`), 글자는 귀를 피해 아래로(`padding-top:.62em`).
- 눈 = **한글 자음 · 영문 · 숫자 · 기본 기호** 중 하나(예: `ㅍ`, `K`, `^`, `o`, `x`, `>`). 기본값은 닉네임 첫 글자. 입 = `ㅅ ω w ㅁ ㅇ ▽ 3 ㅡ _ ㅂ`(기본 `ㅅ`).
- 예: 픽셀상점 → `ㅍㅅㅍ`, 오렌지맛이 고른 기호 → `^ω^`.
- 글자 흰색 800, 자간 -0.06em, `inline-flex` 가운데 정렬(**grid 금지** — 글자가 세로로 쌓임).
- 크기: `xs 20`(목록 메타) · `sm 26`(카드 메이커 자리 기본) · `md 32`(4열 카드) · `lg 54`(로그인 띠) · 프로필 페이지 96~168.
- 아트·색 바탕 위에 얹을 때는 **실루엣 모양의 흰 테두리**(`::after` 로 같은 마스크를 9% 크게).
- 더 예쁘게 하는 방법(귀 모양 · 눈썹 · 볼 · 무늬), 꾸미기 아이템 · 뽑기는 먼 미래 → [`../../product/roadmap-ideas.md`](../../product/roadmap-ideas.md).

### 2.2 타일 색
- **플레이어**: 12색 중 하나(가입 때 무작위, 프로필에서 바꿈). 12색 모두 같은 휘도 Y .155 · 채도 상한 C .12 — 흰 글자 5.1:1, 차분한 톤([`tools/faces.py`](../tools/faces.py)).

  | 홍 | 주 | 귤 | 황 | 올리브 | 풀 | 비취 | 청록 | 하늘 | 쪽 | 보라 | 자두 |
  | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
  | `#AC5255` | `#A85831` | `#A05E14` | `#826C01` | `#6B7407` | `#427B35` | `#017E52` | `#0A7A7B` | `#027797` | `#3870B1` | `#7063B0` | `#9B558D` |

- **메이커**: 대표 게임 아트에서 뽑은 대표색의 색상각을 유지하고 휘도를 Y .155 로 맞춘 색(업로드 때 서버에서 계산). 같은 계산이라 어떤 게임색이어도 흰 글자 대비가 같다.
- 그라운드 강조색(`#046DCE`, `#D22C02`)과 똑같은 색은 쓰지 않는다 — 각인 장치와 헷갈리지 않게(쪽 타일 `#3870B1` 은 채도를 낮춘 다른 색).

### 2.3 로그인 띠
"로그인하면 내 얼굴이 생겨요" — 게스트 화면 중간, 그라운드 색 띠 위에 얼굴 3개(54px, 흰 테두리 3px). 호버 시 양쪽 얼굴이 살짝 기울며 들린다. 게스트에게만, 화면당 한 번.

### 2.4 나중에
자음 수의 한계·작은 크기에서 비슷해 보이는 문제 → 눈·입 외의 변수(눈썹, 볼, 귀 모양, 배경 무늬) 조합을 후속 과제로 탐색(STATUS 열린 질문).

## 3. 그라운드 색 각인

PlayGround = **쪽빛**, MakersGround = **인주**. UI 는 무채색으로 두고, 아래 **각인 장치에만** 그라운드 색을 확실히 쓴다. 이것만 봐도 어느 그라운드인지 알 수 있어야 한다.

| 장치 | 모양 |
| --- | --- |
| 로고 귀 | 귀 선 색 |
| 활성 메뉴 | 글자 `ink-1` + 아래 3px 밑줄 |
| 주 버튼 | 채움(로그인, 플레이, 이어하기) |
| 섹션 귀 표식 | 섹션 제목 앞 22×12 귀 모양(채움) |
| 배지 | 아트 왼쪽 위 큐레이션 배지 |
| 배너 넘김 | 활성 점(22px 막대) |
| 랭킹 띠 | `accent-tint` 바탕 전폭 띠 + 1~3위 숫자 |
| 로그인 띠 | `accent` 바탕 띠 |
| 진행 막대 | 이어하기 진행률 |
| 포커스 링 | 2px `accent` |
| 푸터 윗선 | 3px |

- **게임 아트 영역에는 쓰지 않는다**(아트의 색은 게임 것).
- 다른 그라운드를 가리킬 때는 그 그라운드 색: 헤더 그라운드 전환의 "MakersGround" 호버 = 인주, 푸터 "게임 올리기" = 인주, PlayGround 안의 메이커 일지 태그 = 인주.

## 4. 게임색 필드

큰 색면의 출처는 항상 게임이다. 메인 배너 슬라이드 바탕 = 그 게임 아트의 대표색 진한 톤 → 슬라이드마다·주마다 화면 색이 바뀐다.
- 대표색 추출: 업로드 때 아트에서 뽑고, 배너용은 흰 글자 4.5:1 이상이 되도록 어둡게.
- 글자는 아트를 덮지 않는다 — 아트 밖 왼쪽 글자 영역 또는 어두운 하단 가림막 위.
- 카드 바탕에는 쓰지 않는다(사용자 피드백 — 카드 바탕색 금지).

## 5. 게임 아트 자리

- 비율 16:9 하나. 아트가 없으면 `sunken` 바탕에 제목 글자(대체 아트, 아래 42px 여백 — 메이커 얼굴 자리).
- 캔버스 견본의 아트는 CSS 추상 그림(`.a-loop` 등). 실제 서비스에서도 **타사 IP·AI 생성 일러스트를 플레이스홀더로 쓰지 않는다.**
