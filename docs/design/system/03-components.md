# 03 · 컴포넌트

v10 홈에서 쓴 것 + 다음 페이지(게임 상세·플레이 화면·다운로드·라이브러리·설정)에 바로 필요한 기본 조작 요소. 크기는 [`tokens.css`](tokens.css) 의 컴포넌트 토큰, 색은 의미 토큰만 쓴다. 그림 견본: 캔버스 `디자인 시스템 · 컴포넌트`. 게임 카드 7종은 [`../03-game-cards.md`](../03-game-cards.md) + 캔버스 `게임 카드 컴포넌트`.

공통 상태 규칙 — 모든 조작 요소는 **기본 · 호버 · 키보드 포커스 · 누름 · 비활성**을 가진다.
- 포커스: `outline 2px accent, offset 2px` (`:focus-visible` 만). 아트 위·띠 위처럼 바탕이 진하면 흰 링.
- 누름: `translateY(1px)`.
- 비활성: 불투명도 .4, 커서 기본, 호버 반응 없음. 이유를 알 수 있으면 비활성 대신 누를 수 있게 두고 안내한다.
- 호버로만 보이는 정보 금지 — 같은 정보가 포커스로도 열리거나, 다른 곳(상세)에 글자로 있다.

## 1. 헤더 `SiteHeader`

`높이 68 · 전폭 sticky · 바탕 bg 94% + 흐림 12px · 아래 1px line`
```
[aDmD 로고] [메뉴: 홈 · 게임 · 랭킹 · 같이 · 잼] ········ [Play|Make 전환] [검색 240] [알림] [얼굴 | 로그인 버튼]
```
- 요소 사이 28px. 로고 22px + 그라운드 이름(14px 800 `ink-2`).
- **메뉴(GNB)**: 16px 700 `ink-3` → 호버 `ink-1` → 현재 `ink-1` + 아래 3px `accent` 밑줄(`aria-current="page"`). 높이는 헤더 전체.
- **그라운드 전환**: `sunken` 알약 안 두 칸(13px 700). 현재 칸 = 그 그라운드 색 채움 + 흰 글자. 다른 칸 호버 = 그 그라운드 색 글자.
- **검색**: 알약 240×40, `sunken`, 돋보기 14 + 자리 글 "게임, 메이커 검색". 포커스 → 흰 바탕 + 안쪽 2px `accent`. 입력 시 아래로 MiniRow 자동완성(최대 6줄, ↑↓ 이동, Enter 이동, Esc 닫기).
- **알림**: 원형 아이콘 버튼 40, 새 알림 = 오른쪽 위 8px 다홍 점 + 흰 테두리 2px. `aria-label="알림 3개"`.
- **테마 전환**: 검색 오른쪽 원형 아이콘 버튼 40 — 라이트에선 달, 다크에선 해. `aria-label="다크 모드 전환"`, 선택은 기기에 저장, 첫 방문은 라이트(ADR 0008). 모바일은 상단 바 검색 왼쪽.
- 회원 = 자모 얼굴 32(누르면 메뉴), 게스트 = 작은 주 버튼 "로그인".

## 2. 버튼 `Button`

| 종류 | 모양 | 쓰는 곳 |
| --- | --- | --- |
| `primary` | `accent` 채움 · 흰 글자 → 호버 `accent-strong` | 화면의 주 행동 하나(플레이, 이어하기, 로그인) |
| `secondary` | `sunken` 채움 · `ink-1` → 호버 `sunken-hover` | 보조 행동(게임 검색, 취소) |
| `on-color` | 흰 채움 · `ink-1` | 진한 띠·배너 위 주 행동 |
| `glass` | 흰 16% · 흰 글자 → 26% | 진한 띠·배너 위 보조 행동 |
| `danger` | `danger` 채움 · 흰 글자 + 아이콘 | 삭제·신고 확정(대화상자 안에서만) |
| `link` | 글자만 14px 700 `ink-3` → `ink-1` | "전체 보기", "더 보기" |

| 크기 | 높이 | 안쪽 | 반경 | 글자 |
| --- | --- | --- | --- | --- |
| 기본 | 44 | 20 | `md` 10 | 15px 700 |
| 작게 | 38 | 16 | `full` | 14px 700 |
| 원형 아이콘 | 40 (헤더) · 34 (레일 화살표) | — | `full` | 아이콘 16~20 |

- 아이콘 + 글자 간격 6px, 아이콘 16. 한 영역에 `primary` 는 하나.
- 플레이 계열 버튼에는 `data-play` — 호버 시 로고가 장난 표정(02-brand §1.3).
- 불러오는 중: 글자 자리에 같은 폭 유지 + 점 3개 깜빡임, `aria-busy="true"`.

## 3. 칩 · 탭 · 전환

**필터 칩 `Chip`** — 높이 38, 안쪽 15, `full`, 14px 700. 기본 `sunken`·`ink-2` → 호버 `sunken-hover` → 선택(`aria-pressed="true"`) `ink-1` 채움·흰 글자. 뒤에 개수(600, 60%), 앞에 아이콘 14 가능(실행 방식 칩). 칩 사이 8.

**탭 `Tabs`** — 두 가지만.
- 알약 탭(섹션 안 전환, 랭킹 기준): 높이 34, 안쪽 12, 14px 700 `ink-3`. 선택 = `raised-hover` 바탕 + `accent-strong` 글자 + `hairline` 그림자. 옅은 띠 위에서 쓴다. `role="tablist"`, ←→ 이동.
- 밑줄 탭(페이지 안 큰 구획: 게임 상세의 소개·리뷰·일지): 16px 700, 선택 = `ink-1` + 3px `accent` 밑줄(메뉴와 같은 말투).

**태그 `Tag`** — 높이 20, 안쪽 6, `xs`, `sunken`, 12px 700 `ink-2`. 장르·한 판 시간. 누를 수 있으면 호버 `sunken-hover`.

**툴팁 `Tooltip`** (실행 칩 등)
- `surface-ink` 바탕, 흰 글자 13px 600, 안쪽 10/12, `md` 반경, `pop` 그림자, 화살표 10px(2px 둥근 마름모).
- 줄마다 아이콘 13 + 설명. 통과 줄은 `ok-on-ink`.
- 호버·포커스 후 120ms 뒤 140ms 동안 나타남, Esc 로 닫힘, 포인터가 툴팁 위로 옮겨도 유지(WCAG 1.4.13). 브라우저 기본 `title` 금지.
- 잘리지 않게: 아트는 안쪽 이미지 층만 자르고(`.shots`), 칩에 호버 중이면 z 8.

## 5. 섹션 · 레일 · 띠

**섹션 머리 `SectionHead`** — `귀 표식 22×12(accent) + 제목 heading 22px 800 + (오른쪽) 화살표·탭·"전체 보기"`. 제목 → 내용 18px. 부제는 정보가 있을 때만(13px `ink-3`).

**레일 `Rail`** — 가로 한 줄, 카드 사이 16, 오른쪽 끝 7% 흐려짐(다음이 있다는 신호). 넘김은 머리의 ‹ › 원형 34 버튼(끝에서 비활성). 마우스 휠 가로 스크롤, 키보드 Tab 이동 시 자동 스크롤. 스크롤바 숨김.

**배너 캐러셀 `BannerCarousel`** — 높이 380, 가운데 1080 슬라이드 + 양옆 미리보기(45%). 슬라이드 = 왼쪽 글자 영역(안쪽 40/44, 배지 → Gasoek 40 헤드라인 → 16px 설명 → 버튼 둘) + 오른쪽 아트 560. 바탕은 게임색 필드. 오른쪽 아래 넘김 알약(`‹ 1 / 5 ›`, 먹 55% + 흐림), 아래 점(활성 22px `accent` 막대). **자동 넘김 없음.**

**띠 `Band`** — 화면 리듬을 바꾸는 큰 덩어리. 연속 두 번 쓰지 않는다.
| 종류 | 바탕 | 반경 | 안쪽 | 내용 |

| 랭킹 띠 | `accent-tint` 전폭 | 0 | 44/48 | 섹션 머리 + 알약 탭 + RankRow 3×4 |
| 로그인 띠 | `accent` | `2xl` | 30/36 | 얼굴 3 + 제목 + 설명 + `on-color` 버튼. 게스트만 |

## 6. 얼굴 · 진행

**자모 얼굴 `JamoFace`** — 02-brand §2. 크기 xs20 · sm26 · md32 · lg54. 여럿 겹칠 때(팀·참가자) −6px 겹침 + 흰 테두리 2, 4명 넘으면 `+3` 칩.

**진행 막대 `Progress`** — 높이 5, `full`, 바탕 `sunken-hover`, 채움 `accent`. 숫자는 옆에 글자로("진행 45%"). `role="progressbar"` + `aria-valuenow`.

**저장 `SaveToggle`** — 사각 아이콘 버튼 28, `sm` 반경, `ink-3` → 호버 `sunken`·`ink-1`. 저장됨 = 채운 책갈피 `accent-text` + 로고 장난 표정 한 번. `aria-pressed`.

## 9. 상태 화면 `StatePanel`

빈 상태·오류·404·점검을 같은 틀로. `sunken` 바탕 `2xl` 반경(전체 페이지면 바탕 없이), 가운데 정렬, 위아래 64/56.
```
   [고양이 DmD 표정, 96~120px]
   제목 heading-lg 28px 800
   설명 lead 16px ink-2 (한두 문장, 원인 + 할 수 있는 일)
   [primary] [secondary]
```
| 상황 | 표정 | 문구 예 |
| --- | --- | --- |
| 404 | 시무룩 | "찾는 페이지가 없어요" / "주소가 바뀌었거나, 메이커가 게임을 내렸을 수 있어요." / 홈으로 · 게임 검색 |
| 실행 실패 | 시무룩 | "게임을 불러오지 못했어요" / "잠시 후 다시 해 보세요. 계속 안 되면 메이커에게 알려 주세요." / 다시 시도 · 문제 알리기 |
| 빈 상태(라이브러리) | 졸림 | "아직 플레이한 게임이 없어요" / 게임 둘러보기 |
