# 04 · 패턴 — 리듬 · 문구 · 접근성

## 1. 페이지 리듬

"AI가 만든 듯한" 화면의 가장 큰 신호는 **같은 "제목 + 균일 그리드" 섹션의 반복**이다(리서치 02). 섹션마다 아래 세 축 중 하나 이상을 바꾼다.

| 축 | 변주 |
| --- | --- |
| 바탕 | 흰 바탕 · 전폭 옅은 띠(`accent-tint`) · 둥근 색 띠(`accent`) · 먹 띠(`surface-ink`) · 게임색 필드(배너) |
| 배치 | 가로 레일 · 3열 · 4열 그리드 · 3×4 순위 격자 · 비대칭(글자 + 아트) |
| 카드 | PickCard · GameCard · RankRow · ContinueCard · 일지 카드 · 띠 안 요소 |

규칙
1. 같은 배치 + 같은 카드 섹션을 **연속 두 번** 두지 않는다.
2. 띠(색 바탕 덩어리)는 연속하지 않고, 페이지에 최대 3개.
3. 섹션 사이 64px 고정 — 띠는 바깥 여백이 같고 안쪽 여백으로 숨을 만든다.
4. 큰 글자(Gasoek)는 화면당 2~3곳.
5. 확정 홈 v10 의 순서가 기준 예시: 배너(게임색) → 이어하기(3열) → PICK(레일) → 랭킹(옅은 띠·격자) → 시간 칩 + 4열 → 로그인 띠(색) → 일지(4열·인주 태그) → 잼 띠(먹) → 전체 게임(칩 + 4열) → 푸터.

## 2. 문구

한국 서비스에서 실제로 쓰는 말투. 짧게, 사실만.

| 원칙 | 이렇게 | 이렇게 하지 않는다 |
| --- | --- | --- |
| 해요체, 짧게 | "찾는 페이지가 없어요" | "요청하신 페이지를 찾을 수 없습니다" |
| 큐레이션은 익숙한 말 | "이번 주 PICK", "에디터 추천" | "○○가 골랐어요", "이번 주 고른 게임" |
| 번역투·명사 나열 금지 | "메이커 일지" | "게임 뒤의 사람과 과정" |
| 이유는 사실만 | "이번 주 플레이 수 · 완주율 모두 1위" | 1인칭 감상, 큐레이터 이름 |
| 상태는 숫자로 | "진행 45%", "친구 2명이 플레이", "아직 리뷰 3개" | "해봄", "친구 2명이 함", "리뷰를 남겨 주세요!" |
| 버튼은 동사 | "플레이", "이어하기", "다시 시도", "게임 올리기" | "확인"만 단독(무엇을 확인하는지 불분명할 때) |
| 오류 = 원인 + 할 일 | "닉네임은 2~12자로 적어 주세요" | "잘못된 입력입니다" |
| 부제는 정보가 있을 때만 | (생략) | 섹션마다 꾸밈 부제 |

- **이모지 금지**(감정은 고양이 표정과 자모 얼굴이 맡는다). 느낌표는 축하 순간 한 번.
- 숫자·단위: "3분", "1.2GB", "D-3", "12/3 02:00". 큰 수는 "1.2만".
- 메뉴·섹션 이름은 명사 2~5자: 홈 · 게임 · 랭킹 · 같이 · 잼 · 라이브러리.
- 영문 표기: `aDmD`, `PlayGround`, `MakersGround`, `PICK` 만. 나머지는 한국어.

## 3. 접근성 (WCAG 2.2 AA)

| 항목 | 기준 | 시스템에서 지키는 방법 |
| --- | --- | --- |
| 글자 대비 | 4.5:1 (24px 이상·굵은 19px 이상 3:1) | 의미 토큰 조합만 쓰면 충족 — `ink-3` 이상만 글자, `ink-4` 글자 금지 |
| UI 대비 | 3:1 | 포커스 링 `accent` 흰 바탕 5.1:1 · 다크 3.6:1 |
| 최소 글자 | 문장 13px, 본문 15px | 12px 는 굵은 짧은 낱말(배지)만 |
| 누름 영역 | 24×24 이상(AA), 휴대폰 44 | PC 칩 38 · 탭 34 · 화살표 34, 휴대폰에서는 44 로 키움 |
| 키보드 | 모든 조작 Tab 도달, 순서 = 화면 순서 | 레일·탭·메뉴는 화살표 키, 대화상자 포커스 가둠, Esc 닫기 |
| 포커스 표시 | 항상 보임 | `:focus-visible` 2px 링, 진한 바탕 위 흰 링. 헤더에 가려지지 않게 `scroll-padding-top: 68px` |
| 호버 콘텐츠 | 닫기·유지·지속 (1.4.13) | 툴팁은 포커스로도 열림, Esc, 위로 옮겨도 유지 |
| 움직임 | 끌 수 있어야 | `prefers-reduced-motion` 이면 전 모션 0, 고양이 정지, 자동 넘김 없음 |
| 색에만 의존 금지 | | 등락 ▲▼, 검사 결과 아이콘 + 글자, 오류 아이콘 + 문장 |
| 대체 글 | | 게임 아트 `alt="<게임 이름> 대표 그림"`, 장식(귀, 표정) `aria-hidden`. 로고 `aria-label="aDmD 홈"` |
| 카드 | | 카드 전체를 `<a>` 로 감싸지 않음 — 제목 링크를 늘리고 보조 버튼은 그 위 |
| 언어 | | `<html lang="ko">`, 영문 고유명사는 그대로 |

## 4. 다크 모드

- 토큰은 준비돼 있다(01-foundations §1.2). 채움색·아트·게임색 필드는 그대로, 바탕·글자·옅은 바탕만 바뀐다.
- **결정(ADR 0008): MVP 는 라이트만.** 토큰은 남겨 두고 `data-theme`·`prefers-color-scheme` 연결만 끈다. 출시 후 켤 때 아래 목록을 점검한다.
- 다크에서 바뀌는 곳 확인 목록: 헤더 흐림 바탕(`bg` 94%), 랭킹 띠(`accent-tint` → 900), 툴팁(`surface-ink` → 800, 바탕과 구분), 얼굴 흰 테두리(그대로 흰색 — 아트 위 구분용).
