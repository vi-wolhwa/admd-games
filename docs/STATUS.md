## 확정된 디자인 결정 (요약 — 근거는 02·03 문서)

- PC 는 사이드바 없는 한 열(1200px), 헤더 한 줄, 배너 캐러셀(수동), 가로 레일, 탭 랭킹, 촘촘한 카드 그리드(홈 전체 게임 4열). 흰 바탕 + 여백 구분, 상자 위젯·옛 포털 장치 금지. 모바일 PlayGround 는 나중에 별도 디자인.
- 색: 흑연 무채색 UI + 그라운드 강조색 — **쪽빛 `#046DCE`(Play) / 인주 `#D22C02`(Make)**, 비취 `#047F3F`(통과), 다홍 `#DB0240`(오류·상승). Tailwind 기본 팔레트 금지. 그라운드 색 각인 장치: 로고 귀, 메뉴 밑줄, 로그인 버튼, 섹션 귀 표식, 배지, 랭킹 띠, 로그인 띠, 푸터 윗선.
- 글자: Pretendard(본문·UI) + Gasoek One(28px 이상 큰 목소리만).
- 브랜드 얼굴: **고양이 DmD** — D 는 똑바로, 위에 귀·이마 윤곽. 표정 = D 회전(위 = 장난, 아래 = 시무룩/404). 로고는 가끔 저절로 눈을 굴림.
- 사람 얼굴: **자모 얼굴 아바타**(`ㅍㅅㅍ`) — 모든 사용자 기본 프로필. "로그인하면 내 얼굴이 생겨요" 띠.
- 카드: 아트 16:9 하나, 아트 위 자리 고정(왼쪽 위 배지 · 오른쪽 위 실행 칩 + aDmD 툴팁 · 왼쪽 아래 메이커 얼굴 · 오른쪽 아래 빠른 플레이 · 아래 진행 막대). **카드에 배경색 깔지 않음.** 평점은 리뷰 10개 이상, 플레이 수 같은 허영 지표 금지.
- 문구: 한국 서비스다운 자연스러운 말. **"누가 골랐다" 표현 금지**("이번 주 PICK"), 번역투 금지, 이모지 금지.
